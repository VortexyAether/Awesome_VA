## New Papers / Tools

### SpeND — polynomial consistency is a subspace, not a high-k operator

- Link: https://arxiv.org/abs/2609.02833
- Type: Paper / mesh-free spectral-like discretisation (no public code in HTML)
- Why it matters: 스텐실이 제약보다 크면 남는 자유도는 커널이 암묵 선택한다. 다항식 일치는 저파수 극한만 묶는다. SpeND는 로컬 노드 기하로 가중치를 예측한 뒤 **하드 프로젝션**으로 4차 일치를 구성 보장한다.
- Evidence: abs 2026-09-02; Starepravo/Broadley/King/Lind. Manchester + Cardiff. Title: Learning Spectral-Like Mesh-Free Discretisations. Abstract/HTML: self-supervised, no reference PDE solution; disordered 2D, same stencil |N_a|=30, p=4, wider spectral band than LABFM / 4th-order FD; refinement recovers 4th-order.
- Caveat: 코드 경로 미확인 → Test 불가. 2D 노드 모달 분석. SPH 유체 롤아웃 미기재.
- VA relevance: 어제 SC-NO Jacobian 감독의 **이산 연산자** 짝. Urban_Flighter 메시프리/고파수 카드는 다항식 차수가 아니라 스펙트럴 응답.
- Action: Read/Cite

### Causal constitutive neural operator — history is a function-to-function map

- Link: https://arxiv.org/abs/2609.02194
- Type: Paper / constitutive neural operator (cs-adjacent mechanics; no public code in HTML)
- Why it matters: 내부변수가 안 보이는 실험에서 변형 이력→응력 맵. RNN이 아니라 전체 경로 병렬 전방 + **인과 마스크 어텐션** + 스펙트럴 컨볼루션 + SIREN. 학습 N=50, 같은 물리 경로를 N=1000 (20×)로 잘라도 오차가 거의 평탄.
- Evidence: abs 2026-09-02; Arora/Scheunemann/Brepols/Rezaei. RWTH + ACCESS. Abstract: rate-independent plasticity and ductile damage; internal states unmeasured.
- Caveat: 합성 구성법칙 벤치. 실험 응력-변형만으로 내부상태 식별은 미증명. 코드 미확인.
- VA relevance: 어제 SC-NO 롤아웃의 **경로 인과** 짝. 점 응력 RMSE ≠ 이력 게이트.
- Action: Read/Cite

### GRADSOLVE — exact discrete adjoint of the steps you actually took

- Link: https://arxiv.org/abs/2609.02876
- Code: https://github.com/ECLIPSE-AI4Science/gradsolve
- Docs: https://eclipse-ai4science.github.io/gradsolve/
- Type: Paper + MIT JAX GPU ODE ensemble solver (Python)
- Why it matters: 빠른 GPU 앙상블은 역모드가 느리고, 미분용 솔버는 전방이 느리다. 적응 솔버가 **수락한 스텝을 기록**하고 고정 길이 리플레이의 정확한 이산 adjoint를 계산한다 (Diffrax 기본과 동일, 더 싼 체인).
- Evidence: abs 2026-09-02; Spurio Mancini. RHUL. Abstract: forward kernel **2.8×** vs DiffEqGPU.jl; recorded reverse **5.6–14.1×** vs Diffrax checkpointed adjoint at matched forward-state accuracy, three GPU generations. GitHub `ECLIPSE-AI4Science/gradsolve` ★**5**, **MIT**, Python, pushed 2026-09-03, created 2026-09-02.
- Caveat: **저차원 ODE 앙상블**. CFD/비구조 격자 아님. stiff는 타이트 허용오차에서 패리티. ★5. 로컬 smoke 전 Test 보류.
- VA relevance: 어제 adjoint-vs-PINN 역문제 키의 **실행된 스텝** 짝. 연속 adjoint 근사 ≠ 이산 스텝 감사.
- Action: Read/Save

### SHoSP — robust TO as a first-order worst-case mass budget

- Link: https://arxiv.org/abs/2608.30499
- Reanalysis: https://github.com/PSLer/MiniFEM
- Type: Paper + BSD-2-Clause MATLAB FEM reanalysis (not the SHoSP loop itself)
- Why it matters: 결정론 TO는 힌지·응력 집중에 약하고, 샘플 robust TO는 비싸다. 목적에 민감도 smooth-max를 더하고, 이를 **재료질량 섭동 예산의 1차 최악**으로 해석한다. 추가 adjoint는 같은 강성 행렬.
- Evidence: abs 2026-08-31; Wang/Aage/Sigmund. DTU. Abstract: compliance + compliant mechanisms; porous infill, multi-load, large 3D; structured-mesh stress effects cross-checked with stress-constrained TO + body-fitted FEM. GitHub `PSLer/MiniFEM` ★**2**, **BSD-2-Clause**, MATLAB, pushed 2026-08-24.
- Caveat: MiniFEM은 재해석 패키지. SHoSP 최적화 루프 전용 레포는 별개일 수 있음. ★2.
- VA relevance: 어제 JAX CHT TO의 **취약성 QoI** 짝. 컴플라이언스 ↓ ≠ 힌지 게이트.

## Engineering-AI Pattern

**Do not ship a stencil, a constitutive operator, or an ODE adjoint with only a residual or a 1-step RMSE.** Bind leftover stencil degrees of freedom to a hard consistency subspace (today SpeND), bind path maps to causal history under resolution change (today constitutive NO), and differentiate the recorded adaptive steps rather than a continuous adjoint story (today GRADSOLVE). A TO card that lowers compliance can still hide a hinge.
