### Polyconvex mixture — a material family is a shared potential basis

- Link: https://arxiv.org/abs/2609.00359
- Type: Paper / parametric hyperelasticity foundation model (physics.comp-ph + cond-mat.mtrl-sci; no public code in HTML)
- Why it matters: 고정 초탄성 식이 조성 가족을 못 덮고, 조성마다 따로 맞추면 새 조성 예측이 없다. 각 포텐셜은 폴리컨벡스 불변량에서 볼록·단조이고, 조건화 네트워크가 혼합 가중을 고른다.
- Evidence: abs 2026-08-31; Yang/Padmanabha/Seidl/Bouklas. 19 pages. PolyJet 실험 + Gent 합성. Issue Board HTML Table A2: Nmat=6 test RMSE (Mat+Mode) **0.2744 vs 0.701**; Nmat=24 **0.0472 vs 0.0684**. Train RMSE는 비슷 (**0.0256 vs 0.0263**).
- Caveat: 코드 URL 없음 → Test 불가. 3D 프린트 수지·Gent 벤치. 유체 구성방정식 직접 이전 아님.
- VA relevance: 09-04 인과 구성 NO의 **조성 가족** 짝. 미지 조성+하중 일반화가 train RMSE와 갈라진다.
- Action: Read/Cite

### GUA — conflict-free gradient surgery can be undone by the optimizer

- Link: https://arxiv.org/abs/2609.01558
- Code: https://github.com/JingXiao10/GUA
- Type: Paper + MIT PINN optimizer alignment (cs.LG)
- Why it matters: 손실별 그래디언트 수술이 만든 방향 `a_t`가 충돌 원뿔 안에 있어도, 모멘텀·적응스케일·프리컨디션이 `u_t`를 원뿔 밖으로 민다 (GUM). GUA는 적용 업데이트를 다시 투영하고 옵티마이저 상태도 맞춘다.
- Evidence: abs 2026-09-01; Xiao/Chen/Wang/Jia/Lai. PINN 잔차 vs IC/BC. Issue Board HTML: M-SGD Ru **51.3–86.3%**. 전 PINN 설정에서 GUA 적용 업데이트 충돌 0. 상대 L2 감소 **11.6–98.2%**. Burgers/Kovasznay/Beltrami/Heat-MS. GitHub `JingXiao10/GUA` ★**9**, **MIT**, pushed 2026-09-02. Official GUA implementation.
- Caveat: 1D/2D 표준 PINN 벤치. ★9. CelebA 멀티태스크는 인접. 3D CFD PINN 미검증. Smoke locally before Test.
- VA relevance: 어제 SWE-Gate 기능테스트≠리뷰의 **적용된 업데이트** 짝. PINN 충돌 수술은 옵티마이저 상태까지 안 맞추면 허위 그린라이트.
- Action: Read/Cite/Test

### MPS turbulence encoding — field fidelity is not dissipation fidelity

- Link: https://arxiv.org/abs/2608.28869
- Type: Paper / tensor-network a priori turbulence encoding (physics.flu-dyn + cs.CE; no public code in HTML)
- Why it matters: 등방 난류 DNS를 MPS SVD 절단으로 줄이면 속도 **99.8% fidelity / 원본 메모리 5%**, 스칼라는 같은 fidelity에 **15%**. 운동에너지 상대오차 **0.2%**인데 평균 소산·스칼라 소산은 **~10%**.
- Evidence: abs 2026-08-28; Esmaeili/Alipanah/Pinkston/Givi/Livescu. 23 pages, 17 figures. 비압축 3D 유체 + Fickian 스칼라 DNS. 저파수 스펙트럼은 DNS에 가깝고, 절단이 강해지면 구배량이 먼저 깨진다.
- Caveat: a priori 인코딩이지 NS 시간전진이 아님. 등방 HIT. 벽난류/반응류는 미래 과제. 코드 없음.
- VA relevance: 어제 확률 OpInf의 평균+공분산 게이트와 짝. Urban_Flighter 압축 카드는 KE만 맞추면 안 된다.
- Action: Read/Cite

### Boltzmann ROM — inverse cost needs mass-conserving residual minimization

- Link: https://arxiv.org/abs/2609.02578
- Type: Paper / parametric Boltzmann ROM + inverse (math.NA + math.OC; no public code in HTML)
- Why it matters: 정상 볼츠만 역문제는 FOM을 반복한다. greedy 잔차 공간 + **질량보존 제약 잔차 최소화**. 충돌 커널의 이차 구조와 분리 근사로 온라인 비용을 깎고, 온도 관측으로 충돌 파라미터를 재구성한다.
- Evidence: abs 2026-09-02; Tong/Hu/Li/Shen/Yang. Issue Board HTML: ROM vs FOM 속도 **>10³**, 상대오차 **~0.01%**. 온라인 ≥**200×**. 역문제는 FOM 수천 초 대비 자릿수 단축.
- Caveat: 노이즈 관측 미제시. 코드 없음. 희박기체/열구동 설정. 일반 NS 이전은 별 트랙.
- VA relevance: 축소공간이 질량을 누수하면 역문제 QoI가 가짜로 싸진다.
- Action: Read/Cite
