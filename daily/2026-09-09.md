## New Papers / Tools

### DeepONet attention — cross-attention is the operator, self-attention+dot-product is not free lunch

- Link: https://arxiv.org/abs/2609.04407
- Type: Paper / DeepONet attention ablation (cs.LG; no public code in HTML)
- Why it matters: 어텐션 NO는 보통 여러 축을 한 번에 바꾼다. 다섯 변형을 데이터 학습과 물리정보 학습에 같은 세트로 돌려 크로스어텐션·셀프어텐션·토큰화·깊이를 분리한다. 센서 토큰+쿼리 크로스어텐션이 고전 DeepONet 평균 상대 L2를 **2.4–28×** 줄인다. 브랜치 셀프어텐션+점곱만(V3)은 1D에서 오차를 키운다.
- Evidence: abs 2026-09-03; Amar Alem Koric/Qibang Liu/Seid Koric. 25 pages, 13 figures, 5 tables. 1D 확산–반응, 1D Burgers, 2D Poisson. 최고 구성 **3.5–32.3×**. Issue Board HTML Table 3 (단위 10^{-2}): 데이터 Burgers V1 **4.06e-2** vs V5 **5.27e-3**; 물리정보 Burgers V1 **1.24e-1** vs V4 **7.04e-3** (~17.6×).
- Caveat: 1D/2D 연습 PDE. 산업 메시·3D CFD 아님. 코드 게재 후 → 지금은 Test/Save 금지. HTML `jax-ml/jax`는 의존성이지 논문 레포 아님.
- VA relevance: 어제 APEBench “솔버 역할 분리”의 **융합 위치** 짝. 어텐션 패키지 카드는 크로스어텐션 유무를 먼저 물어야 한다.
- Action: Read/Cite

### LA-NODE — reduced-order self-intersections are a missing latent dimension, not more layers

- Link: https://arxiv.org/abs/2608.22142
- Type: Paper / latent-augmented Neural ODE ROM (cs.LG; no public code in HTML)
- Why it matters: 산업 ROM은 위상공간에서 궤적이 자기교차하면 같은 축소상태에 서로 다른 속도가 붙는다. NODE/Transformer를 깊게 쌓아도 한 점이 두 속도를 가질 수 없다. 잠복 증강 차원의 최소치를 특이점의 속도 모호성 랭크로 준다.
- Evidence: abs 2026-08-22; Wang/Zhou/Mei/Zheng/Bai/Nagahara. IPMSM 드라이브 + 분산에너지(DES). Issue Board HTML: IPMSM 학습 MSE **[1e-5, 1e-4]** vs ANODE/Transformer **[1e-4, 1e-3]**. 필요 이상으로 키우면 이득 없음(정리 1).
- Caveat: 저차원 매니폴드 실증. 고차원 CFD 장 롤아웃 미검증. 코드 없음. 확률 섭동/OOD는 저자들도 미정량.
- VA relevance: 컴팩트 잠복 ≠ 유일 동역학. Urban_Flighter/후류 ROM이 모드 에너지 95%만 보고 벡터장을 믿으면 안 된다.
- Action: Read/Cite

### FS-ENGD-PINN — coupled poroelasticity needs split + energy natural gradient, not a deeper residual net

- Link: https://arxiv.org/abs/2608.26303
- Type: Paper / Fixed-Stress + ENGD PINN (math.NA + math.OC; CiCP accepted; no public code in HTML)
- Why it matters: 어제 ENPINN(에너지놈)과 GUA(옵티마이저)의 결합판. Biot 압밀은 물리 결합+최적화 조건이 둘 다 나쁘다. Fixed-Stress로 역학/유동을 나누고 ENGD로 손실 기하를 맞춘다. 스플릿 없이 변위는 상대오차 **1.0에 정체**.
- Evidence: abs 2026-08-26; Sun/Liu/Feng/Cai. 11 figures. Mandel-Cryer 비단조, 층상 Terzaghi, 3D. Issue Board HTML: Example 3 오차 ~2e-4. Adam 단독은 변위 실패. 3장 혼합형식이 체적 잠김을 줄인다.
- Caveat: 공탄성. 외부 공기역학 CFD 직접 이전 아님. 코드 없음.
- VA relevance: 결합 PINN은 잔차망 깊이보다 **분리 계약 + 손실 기하**가 게이트.
- Action: Read/Cite

### Multi-index Bell PINN — high-order mixed derivatives are a tabulated Faà-di-Bruno, not nested AD

- Link: https://arxiv.org/abs/2609.03768
- Code: https://github.com/fimoto/DNNF90
- Type: Paper + Fortran PINN derivative engine (physics.comp-ph + physics.plasm-ph)
- Why it matters: 고차 PDE PINN은 AD를 K번 접으면 그래프가 폭발한다. 필요한 multi-index만 전방 Faà di Bruno + 벨 계수를 한 번 표로 만든다. 7차 ZK 잔차에서 해 상대오차 **6e-4**인데 7차 미분 놈은 정확값의 **2배** — 잔차 조합 ≠ 모든 미분 정확.
- Evidence: abs 2026-09-03; Imoto. 3·5·7차 분산, 비압축, 5장 EHD. 1 CPU에서 4입력 7차 혼합미분 330개. GitHub `fimoto/DNNF90` ★**0**, license **NOASSERTION**, pushed 2026-09-03.
- Caveat: 저차원 분산 PDE / 플라스마 인접. 3D 비정렬 CFD 아님. ★0 + 비표준 라이선스 → Save/Test 보류, 로컬 스모크만.
- VA relevance: 고차 PINN 청구는 nested AD 메모리 실패와 미분 놈 정확을 같이 물어야 한다.
- Action: Read/Cite

### Wind-turbine wake dissipation — Cε is an FST-flavour field, not a universal constant

- Link: https://arxiv.org/abs/2609.03996
- Type: Paper / experimental wake dissipation (physics.flu-dyn; no public code)
- Why it matters: 후류 TKE 소산이 자유흐름 난류 “맛”에 따라 환형 고Cε 띠를 만든다. 저·중 FST에서 날개끝 Cε가 √Re_D / Re_λ 스케일(비평형). 고강도 FST는 팁 와를 깎아 같은 스케일이 안 잡힌다.
- Evidence: abs 2026-09-03; Bourhis/Buxton. D=0.58 m. Issue Board HTML: I∞ 1–11%, ℒ∞/D 0.1–2. I∞≤5.8%는 x/D=20까지 자기유사, 고강도 L7/L8은 깨진다. 고파수 모델이 ε의 <7%.
- Caveat: 실험 풍력 후류. ML 없음. 실스케일 단지 아님.
- VA relevance: Urban_Flighter/드론 후류 서러게이트가 단일 Cε를 쓰면 FST 전이에 속는다.
- Action: Read/Cite
