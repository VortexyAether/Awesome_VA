### Data-driven hypersonic NEQ ROM with catalytic surfaces

- Link: https://arxiv.org/abs/2608.14445
- Type: Paper / thermochemistry ROM (physics.flu-dyn)
- Why it matters: 촉매 벽 패치는 열유속·화학종 점프를 만든다. 필드 RMSE 서rogate가 깨지는 전형. Scherding-class ROM을 이 불연속에 확장하고 Sammon-type stress로 latent folding을 막는다.
- Evidence: API 2026-08-14; Issue Board HTML — 전체 시뮬 비용 **~50%** 절감; \(Re_x\in[1.4\times10^5,10^6]\), 촉매 패치 \([4\times10^5,6\times10^5]\); a priori 온도 상대오차 well below 1% class (Issue Board / daily_three PDF Fig.7).
- Caveat: 공개 코드 미확인. Mutation++ 계열 극초음속 라이브러리 의존 — Urban 저속 외기와 도메인 거리. 이식 가능한 것은 **벽면 불연속 QoI + 비용 게이트** 패턴. (issue_board_daily_three already public-posted this ID today → Awosome public angle switches to HI-MGN.)
- VA relevance: 공정/재진입/촉매 패치처럼 **벽면 QoI가 1급**인 서rogate 평가 언어.
- Action: Read/Cite/Save

### HI-MeshGraphNets — hierarchical MeshGraphNets

- Link: https://arxiv.org/abs/2608.13827
- Code: https://github.com/leesihun/MeshGraphNets (★0, license unset, pushed 2026-07-13)
- Type: Paper + early public mesh-GNN runtime
- Why it matters: 평탄 MGN은 hop=1이라 고정밀 메시에서 깊이·VRAM·over-smoothing이 동시에 터진다. FPS+Voronoi 계층 + learned interpolation으로 장거리 통신을 값싸게.
- Evidence: cs.LG 2026-08-13; README confirms hierarchical V-cycle message passing by SiHun Lee (not the DeepMind original). Issue Board Tables 2–3: rectangular inclusion stress/disp \(R^2\) **0.99 / 0.99** vs MGN(28MP) **0.85 / −0.11**; VRAM **10.45 vs 17.03 GB**; train **10.18 vs 25.41 h**. Time-averaged Table 5: stress \(R^2\) 0.90 vs 0.72–0.77.
- Caveat: ★0 + SPDX unset → Test, not product Save. 벤치가 구조/접촉 중심 — 외기 CFD family는 별도. 레포 이름이 원본 MeshGraphNets와 겹침.
- VA relevance: 비구조 메시 서rogate의 **iso-cost + long-range** 게이트. 기존 DeepMind MeshGraphNets 엔트리와 **별도 ID**.

### Conservative discrete FV structure vs learned rollout

- Link: https://arxiv.org/abs/2606.01366
- Code: https://github.com/Airscker/DDP-benchmark (★0, license unset, pushed 2026-06-07)
- Type: Paper + structure-preserving 1D DDP benchmark
- Why it matters: 1-step MSE 승자가 장주기에서 지는 직접 반례. 고전 conservative FV 코어만으로 near-roundoff rollout — 학습 보정은 부가.
- Evidence: cs.CE 2026-05-31; rollout MSE **\(7.35\times10^{-9}\)** vs unconstrained **42.3**, Poisson-recompute 25.3, charge-projection 67.2, 4-step rollout train 27.1. 64 config 중 rollout 승 **60/64**, 1-step 승은 **19/64**. README matches the paper (GitHub API description is stale/unrelated).
- Caveat: 1D drift–diffusion–Poisson prototype, sheath wall physics 미구현. ★0 + license unset. 플라즈마 도메인 — 메시지(이산 보존 > 신경망 회귀)만 CFD 롤아웃과 동일 축.
- VA relevance: HERO/Diagnostics-for-Physics 옆 **structure > learned head** 인용.
- Action: Read/Cite/Test (license gate)

- Why it matters: 어제 BTF-PINN(interior-only Dirichlet)의 짝. implicit geometry에 traction hard-enforce. all-soft는 정확·느리고 all-hard는 빠르고 덜 정확 — BC는 페널티 복권이 아님.

- VA relevance: PINN essential-BC contract 언어를 **implicit geometry + hard/soft tradeoff**로 확장.
- Action: Read/Cite

### NestyNet — analytic segmented surrogate + second-order LM

- Link: https://arxiv.org/abs/2608.05862
- Code: https://github.com/RodrigoIbata/NestyNet (★6, SPDX NOASSERTION / README badge MPL-2.0, pushed 2026-08-06)
- Type: Paper + live SciML fitting library
- Why it matters: 표준 NN이 못 맞추는 stiff 물리함수를 segmented analytic + Levenberg–Marquardt로. 값/도함수/적분을 값싼 analytic 경로로.
- Evidence: astro-ph.IM 2026-08-06; AI Feynman 120식 — Adam MLP 대비 median **2100× / 1400× / 780×** (값/1차/2차); L-BFGS 후에도 **540×/450×/250×**; autograd 대비 **~44×**.
- Caveat: 물리함수/식 벤치이지 CFD 장 서rogate가 아님. ×배수는 벤치 선택에 민감. SPDX API ≠ README badge → 라이선스 재확인.
- VA relevance: 도함수/적분 충실도가 필요한 국소 surrogate 기판 후보. Test only.
- Action: Read/Test/Watch
