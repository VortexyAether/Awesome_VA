### Complementary PINNs — SIREN+causal unlocks DFG wake; stacking collapses

- Link: https://arxiv.org/abs/2608.19632
- Code: https://github.com/deveshshah1/Navier_Stokes_Exploration_with_PINNs
- Type: Paper + MIT PINN ablation (cs.LG + physics.flu-dyn)
- Why it matters: PINN 기법은 보통 하나씩 자랑한다. DFG/Schäfer–Turek 비정상 원주 후류에서 **개별 기법은 베이스라인과 같고**, 주기 활성(SIREN)+인과 가중만 박리 톤을 살린다. 그 위에 self-adaptive나 Fourier를 더 쌓으면 필드가 다시 죽는다.
- Evidence: API 2026-08-20; Shah. 초록: OpenFOAM 대비 평균 Rel.L2 **4.1%**. HTML Table 2 기본 SIREN+causal **Ux/Uy/p 7.8% / 17.1% / 16.7%**, St **0.300**, 후류 상관 **0.988**. +Self-Adaptive **21.8 / 75.7 / 37.9**; Fourier+SIREN+causal **58.1 / 99.8 / 98.1**. Re=20 정상장은 Rel.L2 **≤3%**; Re=100 미처리 **68 / 86 / 118%**. GitHub ★0 MIT pushed 2026-08-20.
- Caveat: 2D 층류 icoFoam 벤치. 3D/고Re에서 같은 짝이 성립한다고 쓰지 말 것. 초록 4.1%는 용량/예산 스케일 후 헤드라인으로 읽고, Table 2 기본 페어링 숫자와 같이 적을 것.

### REC-trunk DeepONet — rational+Chebyshev dictionary for high-Péclet walls

- Link: https://arxiv.org/abs/2608.19658
- Type: Paper / DeepONet trunk design (cs.LG + math.NA)
- Why it matters: 고 Peclet 입구 열/물질전달은 얇은 벽층에서 바닐라 트렁크가 진동한다. 학습 전 AAA 유리 기저를 Chebyshev 사전에 얹은 REC 트렁크가 **벽법선 프로파일**에서 이득이 가장 크다.
- Evidence: API 2026-08-20; Choi/Kumar (Georgia Tech); 39pp / 9 figs; 5-seed. 초록: ε∈[1.00e-4, 1.78e-4]에서 Chebyshev 대비 프로파일 오차 **최대 19.5%** 감소. 벽법선 온도/농도에서 바닐라 **60.2%**, Chebyshev **32.2%** 감소. Pe 또는 Pe_m **10²–10⁴**. 공개 코드 없음.
- Caveat: 1D/입구층 연산자. 외기 CFD 메시 전이가 아님. Chebyshev와 스칼라 BVP는 대체로 비슷하고 이득은 가장 얇은 층·벽면에서.
- VA relevance: 층이 얇아질 때 **트렁크 사전**을 먼저 갈라라. 브랜치 폭만 키우지 말 것.
- Action: Read/Cite

### Differentiable vapor-compression — one JAX residual for size, integrate, MPC

- Link: https://arxiv.org/abs/2608.19552
- Code: https://github.com/smyng91/hvac_designer
- Type: Paper + MIT JAX plant (eess.SY + cs.CE)
- Why it matters: 히트펌프 설계·강성 과도·최적제어가 보통 모델이 갈린다. 유한체적 증기압축을 JAX 잔차 하나로 두고, 변위/팽창밸브/튜브 수를 역산한 뒤 **같은 f**로 TR-BDF2와 implicit-Euler MPC를 돌린다. 질량은 (∂ρ/∂p)_h와 (∂ρ/∂h)_p를 압력식에 넣어 지킨다.
