## New Papers / Tools

### DiffSWE2d — CFL stays in the forward pass; the inverse graph is gauge MSE plus smoothness

- Link: https://arxiv.org/abs/2609.11426
- Code: https://github.com/ZhonghouXu/DiffSWE2d
- Type: Paper + MIT PyTorch SWE solver (physics.flu-dyn + physics.geo-ph)
- Why it matters: 엔지니어링 역문제는 “미분 가능 솔버”가 아니라 **어떤 연산이 그래프에 남느냐**다. HLLC+리미터 SWE를 PyTorch로 올리고, 적응 CFL Δt는 forward 안정성용으로 detach. 손실은 훈련 게이지 수위 MSE + 평활. 어제 IDP 하이브리드 FV(2609.10476)와 짝: 허용집합/CFL은 AD 잔차가 아니라 이산 제약.
- Evidence: API abs 2026-09-10; Zhonghou Xu. 벤치 2개 + 쓰나미 경계파형 역문제. GitHub `ZhonghouXu/DiffSWE2d` ★**0**, **MIT**, Python, forks **4**, pushed 2026-09-11. Issue Board HTML: Monai-valley 게이지 0–2, n=0.01.
- Caveat: 2D 구조격자 SWE. 산업 비구조/토사 이동 아님. ★0 → 로컬 스모크 후 Test. Save는 스모크 전 보류.
- VA relevance: 어제 AD vs 이산화(2609.07437)의 **역문제 그래프** 짝. 홍수 픽셀 RMSE ≠ 게이지 수위.
- Action: Read/Cite/Test

### Canonical B-rep — file topology is not a solid invariant; encoders collapse on the same part

- Link: https://arxiv.org/abs/2609.11573
- Type: Paper / CAD B-rep encoder robustness (cs.CV + cs.AI + cs.CG; no public code in API)
- Why it matters: 같은 솔리드가 커널 rebuild·export 재분할·작업 순서만 달라도 B-rep 그래프가 바뀐다. AAGNet/UV-Net/BRepNet은 표준 벤치에서는 높고, 자동 섭동·FreeCAD 인간 재작성·Fusion 검색에서 붕괴. 정규영역그래프는 솔리드에서 노드/특징/프레임을 뽑아 재분할·강체운동 불변을 주장. 어제 CIT-CAD(2609.07434)와 짝: 실행 가능 ≠ 솔리드 동일.
- Evidence: API abs 2026-09-10; Jiang et al. Issue Board HTML Table 2 MFInstSeg macro mIoU: AAGNet clean **0.9851** → composed **0.0055**. Ours clean **0.9922** → composed **0.9816**. Fusion 360 Gallery **3000** 파트.
- Caveat: 코드 미공개 → Test 불가. 그래프 예측은 이웃 면이 바뀌면 동일 면도 움직일 수 있음(저자 caveat). 산업 커널 솔리드 검사와는 별 축.
- VA relevance: CAD 학습 입력이 파일 그래프면 round-trip에서 벤치가 가짜가 된다.
- Action: Read/Cite

### Variational PI-GNN — put the constitutive jump on the mesh, not in a coordinate PINN width

- Link: https://arxiv.org/abs/2609.10983
- Code: https://github.com/aashay-y/Variational-PIGNN-composites
- Type: Paper + MIT label-free variational GNN (math.NA + cs.LG)
- Why it matters: 바이머티리얼 계면에서 변위는 C0, 면내 응력은 점프. 좌표 PINN은 정규화 폭/계면 페널티에 민감. 이 변분 라벨프리 GNN은 적응 적합 메시 그래프에 요소별 구성법칙을 싣는다. 이질성은 시도장이 아니라 이산화가 운반한다.
- Evidence: API abs 2026-09-10; Yadav/Das/Annabattula. Issue Board HTML: 원형 개재 변위 L2 PINN **0.86%** / PI-GNN **0.17%**, σxx **15.08%** / **7.57%**. 다른 홀드아웃 PINN 변위 **7.66%** vs PI-GNN **0.49%**. 강성비 스윕 von Mises **<3.58%**. GitHub `aashay-y/Variational-PIGNN-composites` ★**0**, **MIT**, Python, pushed 2026-09-10.
- Caveat: 2D 평면응력/비틀림. CFD 아님. ★0. 제품 대체가 아니라 계면 표현 게이트.
- VA relevance: 계면 점프를 페널티 폭에 숨기면 변위 RMSE가 응력집중을 숨긴다.
- Action: Read/Cite/Test
