## New Papers / Tools

### DeepOHeat-v2 — self-improving thermal operator for high-contrast 3D-IC

- Link: https://arxiv.org/abs/2608.16080
- Type: Paper / thermal neural operator (cs.LG + physics.data-an)
- Why it matters: 고대비 다다이 스택에서 연속 physics loss는 계면이 불연속이라 ill-defined이고, 이산화 strong-form Hessian은 \(\kappa_2\approx6\times10^4\)라 1차 최적화가 못 버틴다. 이산 에너지 손실 + matrix preconditioner + hotspot trust gate → 참조 솔버 → 검증 오차가 줄 때만 재학습.
- Evidence: API 2026-08-17; peak temperature error **>30 K → 0.55 K**; returned-design surrogate–true peak gap **1.12 K → 0.11 K**; solve-every-step과 동급, Issue Board HTML **~56×** faster.
- Caveat: 공개 코드 미확인. 3D-IC 도메인 — Urban 외기와 거리. 이식 가능한 것은 **고대비 계면 + 최적화 중 분포 이탈 + 게이트** 패턴. (issue_board_daily_three already public-posted this ID today → Awosome public angle switches to FAST-DeepONet.)
- VA relevance: 열/CFD 서rogate가 설계 루프 안에서 OOD로 나갈 때의 **hotspot QoI + fallback** 언어.
- Action: Read/Cite/Save

### HiFi-BRep — high-fidelity latent B-Rep generation

- Link: https://arxiv.org/abs/2608.16485
- Code: https://github.com/1nnoh/HiFi-BRep (★3, Apache-2.0, pushed 2026-08-18)
- Type: Paper + live CAD generator (CVPR 2026)
- Why it matters: padding 노이즈 + 순차 토폴로지 후처리가 representation/generation brittleness를 만든다. 쿼리로 패딩 제거 + topology-guided attention + 한 스테이지에서 기하·토폴로지 병렬 + 매니폴드 제약을 미분 목적.
- Evidence: API 2026-08-17; README matches paper + HF/ModelScope weights. Issue Board Table 1 DeepCAD: Valid **72.20%** vs DeepCAD 68.20 / BrepDiff 63.69 / DTGBrepGen 43.20 / BRepGen 20.76. Compilability **90.38%** (DTG 92.48이 더 높지만 Valid는 43%). COV **70.40** (DeepCAD 76.67이 더 넓음 — 분포 커버 ≠ 솔리드).
- Caveat: ABC에서 Compilability 35.61 / Valid 32.66으로 급락 — 데이터셋 패밀리 시프트. ★3 신생. (issue_board_daily_three already public-posted this ID today.)
- VA relevance: CAD 에이전트 DONE = **OCCT-class Valid**, not compile%/Chamfer/COV.
- Action: Read/Save/Test

### FAST-DeepONet — factor-augmented branch for high-d PDE inputs

- Link: https://arxiv.org/abs/2608.15408
- Code: https://github.com/kwonji39/FAST-DeepONet (★0, MIT, pushed 2026-08-15)
- Type: Paper + MIT DeepONet runtime
- Why it matters: 센서 좌표를 늘리면 plain DeepONet이 통계적으로 붕괴한다. 고정 스펙트럼 경로 + 정규화된 residual projection. 더 촘촘한 센서 ≠ 더 많은 데이터.
- Evidence: API 2026-08-15; README confirms Kwon/Kim/Lin + `fastnn/` + NSE generator. NS Rel.\(L_2\) plain **0.0394 → 0.1556** (branch 129→8193); FAST stays **~0.04**. NS/Darcy/wave Rel.\(L_2\) **4.7–37.0%** better with **3–7×** fewer parameters.
- Caveat: 좌표-쿼리 DeepONet 계열. ★0. 비구조 메시/고대비 계면은 DeepOHeat 축과 별개. 2D NS/Darcy/wave — 공장 CFD 이전이 아님.
- VA relevance: 관측 해상도를 올리는 실험에서 **붕괴 게이트**를 먼저 적는 언어. Public Threads angle (distinct from today's daily_three DeepOHeat/HiFi-BRep).
- Action: Read/Test/Cite

### BOCoDe — engineering-centered Bayesian optimization benchmark

- Link: https://arxiv.org/abs/2608.15073
- Code: https://github.com/rosenyu304/BOCoDe (★4, MIT, pushed 2026-08-15)
- Type: Paper + PyTorch/BoTorch benchmark library
- Why it matters: BO 평가는 합성/HPO에 갇혀 있다. 159개 엔지니어링 설계 + 제약/다목적/혼합변수. 알고리즘 순위가 도메인 간에 안 옮김.
- Evidence: API 2026-08-15 cs.CE; README: **307** problems (159 eng / 80 HPO / 68 synthetic), 31 algorithms, 5 classes; maximize convention + `gx <= 0` constraints; still under construction.

- VA relevance: 설계 루프 BO를 HPO champion으로 고르지 말 것. optimization-sciml 벤치 계약.
- Action: Save/Test/Cite
