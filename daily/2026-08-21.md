### MOOSEnger — harness closes the model gap on MOOSE multiphysics

- Link: https://arxiv.org/abs/2608.15881
- Type: Paper / agentic CAE harness (cs.LG + cs.CE)
- Why it matters: MOOSE 입력 작성은 전문 지식 병목이다. 검색·실행 진단·메모리 하네스가 있으면 로컬 Gemma4도 단독 프론티어를 압도한다. 성공 정의는 실행+요청 물리/기하/BC/출력 정렬이지 잔차 게이트가 아니다.
- Evidence: API 2026-08-16; Abulawi/Li/Giudicelli/Liu/Permann (INL). HTML Table: Diffusion 23/25 vs 25/25 vs 9/25 vs 0/25; NS **16/25 (64%) vs 21/25 (84%) vs 0 vs 0**; overall **153/200 (76.5%) vs 179/200 (90%) vs 10/200 (5%) vs 0/200**. 원자로 메시에서 Gemma가 GPT를 앞섬(88% vs 84%). 공개 에이전트 레포는 HTML에 없음.
- Caveat: “run successfully + aligned” ≠ 잔차/보존 게이트. HTML 본문 ~18k cleaned. 유체 카테고리는 하네스 안에서도 베이스 추론 갭.
- VA relevance: Urban_Flighter / CAE 에이전트는 **실행+물리 정렬 하네스**가 제품이고, 모델 카드가 제품이 아니다.
- Action: Read/Cite/Save

### Outram Park — agentic OpenFOAM port; V&V is the bottleneck

- Link: https://arxiv.org/abs/2608.17504
- Code: https://github.com/theodoreOnzGit/outram-park-backend
- Related: https://github.com/theodoreOnzGit/tampines-steam-tables
- Type: Paper + early GPL-3.0 Rust OpenFOAM port (physics.comp-ph + cs.SE)
- Why it matters: Claude Code로 OpenFOAM 라이브러리를 Outram-Foam(Rust)으로 이식한다. 생산성은 오르지만 **신뢰 가능한 시뮬 코드의 병목은 생성기가 아니라 인간 V&V**. Ghia cavity / Sod / Moody HEM / Edwards blowdown 영수증이 Foam-Agent 패밀리와 구분된다.
- Evidence: API 2026-08-18; Ong/Wong/Xiao; 78pp / 21 figs / 17 tables. HTML: Ghia Re=100 mesh 20→40에서 최대 점오차 **~6.3% → ~1.9%**; Sod L1 **3.7% → 0.7%** (vanLeer MUSCL). GitHub `outram-park-backend` ★1 GPL-3.0 pushed 2026-08-20; `tampines-steam-tables` ★2 GPL-3.0.
- Caveat: 원자로/이상 HEM 중심 — 외기 CFD 제품 클레임 아님. ★1 신생. 에이전틱 생산성 수치는 정성.
- VA relevance: 에이전트 이식 DONE = **고전 CFD 벤치 영수증**. 컴파일 성공 ≠ 물리 충실.
- Action: Read/Cite/Test

### Flux-form spatiotemporal neural operators — conservation in the update

- Link: https://arxiv.org/abs/2608.18148
- Type: Paper / coarse-grained operator learning (nlin.CD + cs.LG + physics.comp-ph)
- Why it matters: 창 이력→미래 슬랩 연산자에 **발산형 플럭스 업데이트**를 넣어 비보존 아티팩트/발산 롤아웃을 억제. Mori–Zwanzig 메모리 길이도 데이터로 고른다. 1-step RMSE 승자 ≠ 장주기 통계.
- Evidence: API 2026-08-11 (gap-fill). Chen. HTML: Local vs Global vs No conservation. KS 스펙트럼 상대오차 εS **0.08465 (Local) vs 0.2059 (Global)**; No conservation은 조기 불안정. Burgers/KS/2D NS. 공개 코드 미기재.
- Caveat: 필터된 조대장; 공학 기하/BC 게이트는 별도. 08-11 발행 — 오늘 드롭이 아니라 갭 필.
- VA relevance: 오래 틀 연산자는 **들고 나는 양(국소 플럭스)** 부터 맞출 것. 총량만 맞추면 스펙트럼이 남는다.
- Action: Read/Cite

### Intrusive vs non-intrusive ROM for Carreau GNF

- Link: https://arxiv.org/abs/2608.18259
- Type: Paper / non-Newtonian ROM comparison (physics.flu-dyn)
- Why it matters: 동일 POD 스냅샷 위에서 **ROM-FULL (침습 재조립) / ROM-DEIM / ROM-RBF**를 lid-driven cavity + 침강 구에 정직 비교. FULL이 전 영역 최저 오차, RBF는 훈련 밖이 무너짐, DEIM은 효율–정확 타협.
- Evidence: API 2026-08-18; Rai/Spanjaards/Anderson/Wang/Jaensson. Abstract: FULL highest accuracy but full-order nonlinear reassembly; RBF fully non-intrusive and deteriorates outside training; DEIM balances even when data are sparse.
- Caveat: 코드 미확인. 2D 벤치. 난류/외기 전이 없음.
- VA relevance: “서rogate 하나”가 아니라 **솔버 접근권 / 온라인 비용 / 유변 OOD**를 같이 고른다.
- Action: Read/Cite

### PINN inverse granular pipe flow from sparse sensors

- Link: https://arxiv.org/abs/2608.18641
- Type: Paper / inverse PINN (physics.flu-dyn)
- Why it matters: 입·출·벽 BC를 모를 때 CFD가 어려운 역문제. 희소 관측+구성방정식으로 관내 정상 입상유동 전장을 복원. **데이터 볼륨이 줄면 축방향 속도 상대오차가 한 자릿수 붕괴** — 잔차 복권 아님.
- Evidence: API 2026-08-19; Wan/Zhao/Wang. HTML Fig.6: full-field relative error 축속도 **1.1×10⁻²**, 고상분율 1.6×10⁻², 입상온도 3.7×10⁻². 데이터 부족 시 축속도 **1.1×10⁻² → 1.4×10⁻¹**. 랜덤 감독 시 축속도 7.5×10⁻³급. 공개 코드 미기재.
- Caveat: continuum KTGF 라벨(CFD) — DEM/실험 센서는 별도. 파이프 정상장.
- VA relevance: 희소 센서  Inverse PINN DONE = **데이터량 붕괴 곡선**, 한 점 Rel.L2가 아님.
- Action: Read/Cite
