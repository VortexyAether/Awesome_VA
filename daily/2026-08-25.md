## New Papers / Tools

### STCO — prescribed-condition neural operators for IBM CFD

- Link: https://arxiv.org/abs/2608.20477
- Type: Paper / prescribed-condition operator interface (cs.AI)
- Why it matters: 관측 장 + 정적 디스크립터만 받는 NO는 **쿼리 시각의 몸체 운동·유입·외력**을 모른다. STCO는 PCOL 인터페이스(FAGL + DSFiLM)로 이질 백본에 같은 처방 조건을 꽂는다. 제어·형상 변경 배포는 이 쿼리가 없으면 성립하지 않는다.
- Evidence: API 2026-08-20; Yang/Zhang/Li. WaterLily.jl IBM. 12 matched backbones. Abstract: mean paired rel-\(L_2\) **−31.1%**, normalized pressure-derived load **−24.7%**. Longer-lead field error down on **11/12** backbones. Issue Board HTML Table 1: PINO field **0.438→0.194 (+55.7%)**; MGN field **0.438→0.242 (+44.8%)**. ID-Lead \(\Delta n=1\)–20 / OOD-Lead 21–40. 공개 코드 HTML·API 미기재.
- Caveat: IBM 2D/워터릴리 ≠ 외기 RANS 제품. 코드 없음 → Test 보류.
- VA relevance: Urban_Flighter / 제어 서rogate DONE = **처방 운동·BC를 쿼리에 넣고 ID/OOD-Lead를 같이 채점**. 다음 프레임 RMSE만으로는 부족하다.
- Action: Read/Cite/Save

### OpPropRank — shared physics responses rank NO libraries without ground truth

- Link: https://arxiv.org/abs/2608.20441
- Code: https://github.com/ToughClimb/OpPropRank-open-source
- Type: Paper + MIT operator-library ranking runtime (cs.LG + math.NA + physics.comp-ph)
- Why it matters: 배포 때 고충실 해가 없으면 라이브러리에서 무엇을 고를지 모른다. 제곱 Hilbert 손실 아래 순위는 **후보 차분의 저차원 span**에만 의존한다. 원시 잔차 크기는 그 순위를 못 고른다.
- Evidence: API 2026-08-20; Liang/Liu. Fluid / reaction-diffusion / wave; Fourier+conv libraries. Abstract: pairwise **>99.6%**, optimal checkpoint **99.0%**. Issue Board HTML: pairwise **99.59%** (49122/49323), top-1 **99.01%** (1901/1920); two-PDE eight-lib raw residual ~**67.8%**. Strongly monotone discretizations get exact-decision certificates. GitHub `ToughClimb/OpPropRank-open-source` ★0 MIT pushed 2026-08-06 (`main`).
- Caveat: ★0 신생. 푸시가 논문일보다 앞섬. 벤치 PDE ≠ 공학 기하/BC 게이트.
- VA relevance: 연산자 라이브러리 DONE = **공유 물리 응답 순위 + 단조성 증명**. 잔차가 작다는 것만으로는 부족하다.
- Action: Read/Cite/Test/Save

### Low-fidelity aerofoil opt for curvilinear / cyclorotor kinematics

- Link: https://arxiv.org/abs/2608.20951
- Code: https://github.com/BenIrwin95/Low-Fidelity-Cyclorotor-Aerofoil-Optimiser
- Type: Paper + Apache-2.0 MATLAB shape-opt (physics.flu-dyn)
- Why it matters: 동적 실속 LEV를 억누르는 익형 탐색을 **단일 스트림튜브 + LE/TE 분리 목적**으로. 추력 유지 익형 최적화와 피치 기구 최적화(추력 감소)를 분리한다.
- Evidence: API 2026-08-21; Irwin/Toal/Krishna. Hovering cyclorotor. Abstract: 4-blade LF opt captures **77%** of HF Figure-of-Merit gain. Issue Board HTML: baseline FM **0.39** / HF URANS **0.65** / LF **0.59**. NACA 0015, Re~30k, 수조; MATLAB `fminsearch`. GitHub ★0 Apache-2.0 pushed 2026-07-29 (`master`).
- Caveat: ★0. 사이클로로터/호버 — Urban_Flighter 쿼드와 키네마틱이 다름. 2D URANS HF.
- VA relevance: 형상 탐색 DONE = **하류 QoI(FM) + 충실도 사다리**. 싼 점수가 예쁜 날개를 고른 것은 영수증이 아니다.
- Action: Read/Cite/Test

### Point-cloud quality metrics that actually predict meshfree error

- Action: Read/Cite/Save
