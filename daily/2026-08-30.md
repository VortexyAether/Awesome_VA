## New Papers / Tools

### SAR-NOMAD — virtual sensing scores Latency-Error-Energy, not Rel L2 alone

- Link: https://arxiv.org/abs/2608.23987
- Type: Paper / neural operator virtual sensing (cs.LG)
- Why it matters: trunk NOMAD의 ReLU를 **Sparse-Activation-ReLU**로 바꿔 스파이킹·서러게이트 그래디언트 없이 희소 활성. 가상센싱을 엣지에 달 때 Rel L2만 보면 VS는 스파이킹↓와 함께 오차가 무너진다.
- Evidence: abs 2026-08-25; Howes/Ahmed/Alam. Issue Board HTML: 2D 열교환기(딤플+테이프) HX LEE **26.35**, lid-driven cavity LEE **37.96** — VS/LIF-NOMAD 대비 **≥5×**. graph-neighbor thresholding은 HX L2를 KNN 대비 **거의 7배**. 공개 코드 없음.
- Caveat: 2D 단면. SpiNNaker 에너지 보정은 저자도 crude. Test 불가.
- VA relevance: Urban_Flighter / 열-유동 트윈 센서 배치는 **LEE(지연·오차·에너지)**. 예쁜 장 ≠ 현장 센서.
- Action: Read/Cite

### Procedura — admit a part only after compile, mate, and connectivity

- Link: https://arxiv.org/abs/2608.26238
- Code: https://github.com/SpatiaOS/Procedura
- Project: https://spatiaos.github.io/projects/procedura/
- Type: Paper + MIT CAD-as-code agent (cs.CV + cs.GR)
- Why it matters: 네이티브 3D 생성은 날카로운 기계 파트를 부드럽게 만들고 편집 파라미터가 없다. 객체를 **이름 있는 파트 + typed mate 프로그램**으로 쓰고, 배치는 mate frame에서 풀고, **compile/mate/connectivity가 통과해야만 커밋**. 비전 critic은 한 번에 한 진단. 연결성 = 인쇄 가능성 하드 제약.
- Evidence: abs 2026-08-26; Lin/Yang/Hu/Zhou/Zhang/Cao/Liu/Yao. Issue Board HTML: P3D-Bench overall **0.590** (Gemini 3.7 Flash) vs 단일샷 GPT-5.6-sol **0.563**. MechBench-36 hard-surface. GitHub `SpatiaOS/Procedura` ★**94**, **MIT**, pushed 2026-08-27. OpenSCAD Manifold backend required; CGAL fallback measured **1774 s vs 1.77 s** on one `hull()`.
- Caveat: 벤치가 비전 assembly judge. 커널 BRep/STEP validity는 별도. Fusion/OCC MCP 아님. Isaac Sim은 `--motion`만.
- VA relevance: CAD 에이전트 DONE = **compile + mate + connectivity**. 어제 DNO의 “벽은 아키텍처”와 같은 축.
- Action: Read/Save/Test

### PI-SCM — backprop-free PINN; VdP 40 s → 1.44 s, no NS

- Link: https://arxiv.org/abs/2608.26549
- Type: Paper / backpropagation-free PINN (math.NA + cs.AI + cs.LG + eess.SY)
- Why it matters: 비선형 미분연산자의 로컬 자코비안을 해석적으로 써서 물리 손실을 **선형 최소제곱**으로 투영. PI-SC-I/II/III. BP/AD 함정을 우회한다고 해서 NS가 준비된 것은 아니다.
- Evidence: abs 2026-08-27; Song/Chen/Cen/Wu/Zhang. Issue Board HTML Tables: VdP unsupervised PINN 4×64 **40.0 s / RMSE 5.49e-3** vs PI-SC-III **1.44 s / 1.93e-3** (~**28×**). 딥 PINN 대비 시간 1–2 orders; PIELM은 더 빠르지만 RMSE가 **3 orders** 나쁨. Helmholtz/Allen–Cahn. **Navier–Stokes 실험 0건**. 공개 코드 없음.
- Caveat: ODE/선형 PDE 벤치. 유체 기하 없음. Test 금지.
- VA relevance: PINN 가속 카드는 **벤치 클래스**를 같이 적을 것. 초시계 ≠ 비압축 솔버.
- Action: Read/Cite

### Self-augmented diffusion guidance — residual as a sample condition, not a per-step PDE

- Link: https://arxiv.org/abs/2608.26748
- Type: Paper / physics-informed generative fluids (cs.LG)
- Why it matters: 표준 diffusion은 유체 시퀀스를 그릴 수 있지만 동역학을 깨뜨린다. 편차를 조건으로 학습하고 샘플 때 편차=0. **매 디노이즈마다 PDE를 안 품**.
- Evidence: abs 2026-08-27; Osaka/Takeishi/Yairi. Issue Board HTML: Darcy mean residual baseline **4.97e-2** → proposed 1x **1.19e-2** (2x **1.11e-2**). PIDM+CoCoGen **6.90e-3**. 2D 유체 시퀀스 동일 트렌드. 공개 코드 없음.
- Caveat: Darcy + 2D 유체. 잔차↓가 스펙트럼/충격파 보존은 아님.
- VA relevance: 생성 모델 DONE = **잔차 조건**. 시각 그럴듯함 ≠ 지배방정식.
- Action: Cite

## Engineering-AI Pattern

**Do not grade the quantity you will deploy with the quantity that is easy to plot.** Rel L2 can look solved while LEE is not. A mesh that looks assembled can still be disconnected solids. A 28× PINN clock on van der Pol is not a Navier–Stokes receipt. A diffusion sample can look like flow while the residual is still 5e-2.
