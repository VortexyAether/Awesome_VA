## New Papers / Tools

### EvoPINN — agentic discovery of executable PINN algorithms

- Link: https://arxiv.org/abs/2607.26490
- Type: Paper / agentic SciML harness
- Why it matters: Reframes PINN development as execution-grounded algorithm discovery: separate representation vs training program, run structural verification, and accept candidates only under budget-matched PDE evaluations. Autonomously invents SLRC-PINN and reports parameter-matched gains over free-form best-of-N search.
- Evidence: arXiv abstract frames the harness; Issue Board HTML harvest records Burgers1D EvoPINN rel.L2 **1.65e-4 ± 5.2e-5**, SLRC-PINN mean **2.04e-4** (width-matched MLP ~**4.55e-4**), Wave1D **1.39e-2** vs Best-of-56 **2.32e-1**, and a claimed **−55.1%** mean-error cut vs Best-of-56 on the Burgers path.
- Caveat: Standard PDE suite, not industrial mesh/CFD. Clean public code URL was not confirmed at curation time; LLM proposal quality is model-dependent.
- Action: Read/Cite

### Parametric PINN vs tensorial ROM — shallow-water dam-break

- Link: https://arxiv.org/abs/2607.27433
- Type: Paper / parametric SWE surrogate comparison
- Why it matters: Same parametric 1D dam-break map (space, time, parameters → state) for a PINN and a non-intrusive tensorial ROM, with out-of-sample and extrapolated parameters. Makes **shock-aware collocation** an explicit robustness requirement for PINN-style flood/SWE surrogates.
- Evidence: Abstract stresses shock-aware collocation; Issue Board tables e.g. μ=(18,0) t=1 TROM h **3.58e-4** vs PINN h **2.87e-3**; shock-adjacent μ=(26,0.14) t=2 TROM q **2.43e-2** vs PINN q **9.62e-2**.
- Caveat: 1D only; no public code harvested; not a 2D/3D street-network flood QoI claim.
- Action: Read/Cite/Test

### Compactness vs forecast accuracy — controlled wake latent ROMs

- Link: https://arxiv.org/abs/2607.24569
- Type: Paper / control-oriented fluid ROM study
- Why it matters: On actuated truck-wake and fluidic-pinball cases, nonlinear CAE latents can compress sharply yet become broadband/irregular and more likely to diverge over long horizons, while smoother POD latents often support stabler long-horizon predictors. Control-ROM green-light should prioritize forecast horizon stability over max compression — the ROM-side twin of yesterday’s HERO rollout gate.
- Evidence: Abstract frames encoder choice vs latent predictability under control; Issue Board notes short-horizon pinball parity near ~91% with CAE long-horizon decay / higher catastrophic divergence risk.
- Caveat: 2D actuated wakes; accuracy definition is reconstruction-pooled rather than nRMSE@H; no public code.
- Action: Read/Cite

### PINO thermal ranking of low-cost wall materials

- Link: https://arxiv.org/abs/2607.25668
- Data: https://doi.org/10.5281/zenodo.21311299
- Type: Paper + dataset / thermal operator for decision QoI
- Why it matters: FDM (Crank–Nicolson) + PINO (FNO backbone) learns wall-material parameter → temperature-field operators and preserves decision QoIs (peak inner-surface temperature; ISO 13786 time lag / decrement). Data-scarce physics loss improves QoI MAE; material ranking can reverse across climate regimes.
- Evidence: Issue Board harvest: field rel.L2 **5.14e-4**, QoI MAE **0.201 K**, scarce-data QoI cuts **18.8–27.5%**, time-lag MAE **0.99 h**, 1500 LHS samples / 9-D parameter space.
- Caveat: 1D wall heat equation for housing materials, not full-building CFD; method transfer matters more than absolute numbers.
- Action: Read/Test/Cite

### PINN residuals as AMR indicators (FD remains final)

- Link: https://arxiv.org/abs/2606.02475
- Type: Paper / hybrid numerics
- Why it matters: Uses a PINN as an off-grid residual probe to drive cellwise AMR, then solves with classical finite differences. Pattern is “neural diagnoses, solver decides” rather than neural replacement.
- Evidence: Issue Board: Burgers PINN-threshold rel.L2 **0.021** @60 DoF vs uniform **0.023** @192 DoF; matched-mesh error cut **−67.5%** (gradient indicators can still win slightly).
- Caveat: Mostly 1D Burgers / manufactured tests; not industrial 3D FV validation.
- Action: Read/Cite
