## New Papers / Tools

### CT-PIKAN — coordinate-transformed Physics-Informed KAN + autograd metrics

- Link: https://arxiv.org/abs/2608.06660
- Code: https://github.com/m-heravifard/CT-PIKAN
- Type: Paper + open MIT tooling (early)
- Why it matters: Standard PIKAN/PINN stacks assume Cartesian domains. CT-PIKAN maps physical→computational coordinates and evaluates Jacobians/metric tensors/transformed operators via **automatic differentiation**, so curvilinear PDEs do not require hand-derived metric coefficients.
- Evidence: math.NA 2026-08-07; GitHub `m-heravifard/CT-PIKAN` ★0, **MIT**, pushed 2026-08-04; public scripts for 2D curvilinear heat/Poisson. Abstract validates data-free B-spline PIKAN on advection then polar/wavy Poisson–heat–advection benches.
- Caveat: Classical PDE suite, not industrial mesh CFD/BC gates; zero stars; quantitative table harvest weak — treat accuracy claims as author narrative until re-run.
- VA relevance: Geometry-aware mesh-light path between CAD surface coordinates and residual solvers; pairs with curved-boundary numerics and FreeCAD/CadQuery agent geometry handoff.
- Action: Read/Test/Save

### Symplectic Geometric Closure (SGC) — structure-preserving 2D turbulence closure

- Link: https://arxiv.org/abs/2608.06606
- Type: Paper / theory for geometrically constrained SGS
- Why it matters: Frames SGS not as residual fitting but as preserving the **dual-cascade geometry** (forward enstrophy / inverse energy) via a hidden symplectic reservoir and constrained Hamiltonian exchange — online stability by construction.
- Evidence: physics.flu-dyn + math-ph; 58 pages; Kraichnan DIA-compatible operator architecture and \(k^{-5/3}\)/\(k^{-3}\) cascade admission at one-loop dressed Eulerian transfer (theory paper).
- Caveat: 2D theory-first; no public implementation harvested; 3D wall-bounded LES transfer unproven.
- VA relevance: Cite when rejecting “RMSE-only closure” leaderboards and requiring geometric/conservation gates for learned SGS.
- Action: Read/Cite
