### When a neural surrogate cannot accelerate a solver

- Link: https://arxiv.org/abs/2608.23075
- Type: Paper / closed-loop surrogate negative result (astro-ph.IM + astro-ph.HE + cs.LG + physics.comp-ph)
- Why it matters: 호출당 싼 네트워크는 루프를 당기지 못한다. 가속 상한은 **런타임 몫**이지 호출당 배속이 아니다. 오프라인 오차는 배포 순위를 못 매기고, 학습 다양체를 떠난 루프에서 올바른 UQ 게이트는 거의 모든 셀을 미룬다.
- Evidence: API 2026-08-24; Thümmler/Kuroda. 44 pages. GR radiation-hydrodynamics, energy-dependent neutrino–matter Newton block. Exclusive self-time: target **16.9%** of critical-rank wall clock → Amdahl cap **~1.2×**. Surrogate **5.8×** cheaper per call merely ties; crash-free no-fallback config reaches parity. Fourteen networks: pooled Spearman error-vs-survival **ρ=+0.73** is a between-family confound; controlled **ρ=−0.04**. Visited states **73×** off manifold; gate defers **96.8–99.7%** of cells. Gated loop **0.94–0.96×** slowdown. Never-crash gated run: linear density bias **−19.9%** over 6000 steps (directed ballistic bias, not variance-driven AR blow-up). 공개 코드 API 미기재.
- Caveat: Neutrino GR hydro ≠ 외기 RANS. 게이트 경제학은 일반. 코드 없음 → Test 보류.
- VA relevance: Urban_Flighter / 제어 서로게이트 DONE = **Amdahl 몫 + 닫힌루프 분포 + 게이트 포함 벽시계**. 홀드아웃 RMSE로 가속을 주장하면 안 된다.

## Engineering-AI Pattern

**Measure the share of the clock, then refuse residual-as-rank.** A 5.8× cheaper call that owns 16.9% of wall time cannot buy a 5.8× loop. A smaller PDE residual can hide a structural identity violation. Industrial meshes still need both halves of the multigrid cycle.
