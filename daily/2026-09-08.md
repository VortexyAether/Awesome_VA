### ENPINN — sharp-layer PINN needs energy-norm weak loss, not residual derivatives alone

- Link: https://arxiv.org/abs/2608.29499
- Type: Paper / energy-norm PINN (math.NA + math-ph; no public code in HTML)
- Why it matters: 날카로운 경계/내부 층에서 점잔차 PINN이 무너진다. WLPINN(테스트 함수)과 gPINN(잔차 공간미분)의 한계를 분석한 뒤, 에너지놈·그래디언트를 약한형식 손실에 넣는다.
- Evidence: abs 2026-08-30; Maity/Das/Patawari/Jagtap. Combustion, coupled multi-scale, 2D Burgers interior layer, 3D time-dependent. Issue Board HTML: same capacity에서 ENPINN이 gPINN/WLPINN/VSPINN보다 수렴·정확. WLPINN은 학습 중반 상대 L2가 더 좋다가 **정체**.
- Caveat: 코드 URL 없음 → Test 불가. 일반화 대류–확산–반응. 3D CFD 벽난류 미검증. 이동층 비정상·잔차 미분 비용 ≈ gPINN.
- VA relevance: 어제 GUA의 **적용 업데이트** 짝. 손실 기하와 옵티마이저가 둘 다 층 해상의 게이트.
- Action: Read/Cite

### Compact Gaussian kinetics — conserved-moment fidelity is not a validity domain

- Link: https://arxiv.org/abs/2609.04606
- Type: Paper / rarefied kinetic representation (physics.flu-dyn; no public code in HTML)
- Why it matters: DVM 상태를 국소 가우시안 혼합으로 압축. 보존량은 서브퍼센트, 수송·고차 모멘트는 약 1–2%. 같은 계수 예산에서 격자 기저는 비평형량이 89–98%까지 깨진다. Ma12는 정규화 좌표 가드가 거절한다.
- Evidence: abs 2026-09-04; Roohi. Ma3/Ma5 충격 + 공동. 동일 4608-계수에서 수송 1–2% vs 격자 89–98%. withheld Ma6 분포오차 **42.86±5.40% → 11.45±0.94%**, 수송은 여전히 **30–40%**.
- Caveat: 단원자, 충격+공동. NS 시간전진 아님. 코드 없음.
- VA relevance: 어제 MPS 99.8% fidelity / 소산 ~10%와 같은 **표현 리더보드 ≠ QoI**.
- Action: Read/Cite

### APEBench / PRDP — emulator training must name which solver role is being used

- Link: https://arxiv.org/abs/2608.24547
- Code: https://github.com/tum-pbs/apebench
- Type: Thesis + MIT JAX emulator bench (cs.LG; NeurIPS 2024 suite)
- Why it matters: 수치 솔버와 뉴럴 에뮬레이터를 같은 스펙트럼 언어로 읽는다. 솔버는 데이터 생성·감독 손실·하이브리드 미분·벤치마크 기준으로 **역할이 갈린다**. PRDP는 충분히 굵은 물리만으로 네트워크 정확을 낸다.
- Evidence: abs 2026-08-25; Koehler. APEBench + PRDP + Neural Emulator Superiority. Issue Board HTML Ch.13: NS 에뮬 학습시간 **62%** 절감, 솔버 반복 최대 **86%**. GitHub `tum-pbs/apebench` ★**109**, **MIT**, pushed 2026-06-01. ≥46 PDEs 1D/2D/3D.
- Caveat: 학위논문 묶음. apebench 푸시 06-01로 신선 커밋은 아님. 산업 형상 벤치 아님. Smoke locally before Test.
- VA relevance: 훈련 RMSE ≠ 배치 QoI를 에뮬레이터 파이프라인의 **솔버 역할 장부**로 옮긴다.
