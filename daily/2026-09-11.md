## New Papers / Tools

### IDP hybrid FV — cell averages and point values need one local stability certificate on general meshes

- Link: https://arxiv.org/abs/2609.10476
- Type: Paper / invariant-domain hybrid FV (math.NA + physics.comp-ph; no public code in HTML)
- Why it matters: Active Flux/PAMPA처럼 cell-average는 보존, 경계 point-value는 비보존일 수 있다. 허용집합 G를 한 로컬 조건으로 같이 지키지 않으면 하이브리드 이산화는 “평균만 안전”해진다. 사후 수리 없이 a priori 리미터 + barrier–Legendre admissibility transform.
- Evidence: abs 2026-09-09; Ding/Cui/Abgrall/Wu. Issue Board HTML Table 2: 삼각 메시 N=180224 셀평균 L1 **3.92e-5** 관측차수 **3.09**, point **4.01e-5** / **3.12**. 리미터 활성 Λ Finest **1.93%**. Cartesian 640² L1 **1.19e-5** 차수 **2.93**.
- Caveat: 고전 수치해석. ML 서러게이트 아님. 산업 CAD 다면체/OpenFOAM 임포트 데모 없음. 코드 미공개 → Test 불가.
- VA relevance: 어제 AD vs 이산화(2609.07437)의 **이산 제약** 짝. 충격/허용집합은 AD 잔차가 아니라 격자 쪽 증명.
- Action: Read/Cite

### Physics-guided extrapolation — in-domain R² is not a license to leave the Fourier window

- Link: https://arxiv.org/abs/2609.09912
- Type: Paper / PINN–BiLSTM extrapolation protocol (cs.LG; no public code in HTML)
- Why it matters: 엔지니어링 ML의 실제 실패는 보간이 아니라 학습창 밖이다. 해석 가능한 1D 열확산을 sequential train–predict–validate–extend 게이트로 쓴다. 물리 정렬(Root-Fourier, 경계 가중, 하드 BC, log-time) 없이는 조기 Fo의 강스티프 경계층에서 오차가 누적된다.
- Evidence: abs 2026-09-09; Yadav/Dubey/Chakraborty/Akolekar. Issue Board HTML: 보간 Fo=0.002/0.007. PG-BiLSTM R² **0.99003** MAE **0.00607** → R² **0.99953** MAE **0.00239**. 수정 PINN R² **0.99978** MAE **0.00122** / R² **0.99998** MAE **0.00067**. 첫 외삽점 Fo=**0.0009**와 **0.0091**.
- Caveat: 1D Dirichlet 열전도. 3D CFD/비선형물성 아님. 코드 미공개. PINN 보간 숫자가 외삽 성공을 대체하지 않음 — 본문도 그렇게 말함.
- VA relevance: ONECYL 롤아웃+항력과 같은 방향: 학습창 점수는 경계 밖 시계가 아니다.
- Action: Read/Cite

### Two-scale PCA-Net — local PCA patches create block artifacts; a cheap global coarse field is the missing scale

- Link: https://arxiv.org/abs/2609.08034
- Code: https://github.com/dmrigank/PAtch_PCA_methods_extensions
- Type: Paper + MIT two-scale localized PCA operator (cs.LG)
- Why it matters: 패치 PCA는 스케일을 사지만 인터페이스 오프셋·가짜 고파수를 만든다. 조기역 PCA + 로컬 잔차가 블록 아티팩트를 줄인다. 스펙트럴 항은 의도 지표만 개선하고 타일링을 안 고친다고 본문이 말함.
- Evidence: abs 2026-09-07; Dhingra/Stout/San. Issue Board HTML Table 30: Poisson-128 learned MRE Plain L2L **0.04829** vs Two-scale **0.01139** (oracle **0.00501**). SSIM 0.943 → 0.997. GitHub `dmrigank/PAtch_PCA_methods_extensions` ★**0**, **MIT**, pushed 2026-09-10.
- Caveat: 2D Poisson/Darcy. 산업 메시 CFD 아님. ★0. 스펙트럴/PDE residual 가중은 최종 설정에서 0. 로컬 스모크 후 Test.
- VA relevance: 로컬 연산자 카드는 패치 RMSE가 아니라 인터페이스/스펙트럴 아티팩트를 같이 물어야 한다.
- Action: Read/Cite/Test

### FSAN — global flow-condition vectors ignore that different surface patches live in different states

- Link: https://arxiv.org/abs/2609.06660
- Type: Paper / aero surface-Cp operator-on-points (cs.CV + cs.AI; no public code in HTML)
- Why it matters: 기존 서러게이트는 (Ma, Re, AoA)를 모든 표면에 같은 벡터로 넣는다. FSAN은 점군과 유동조건을 분리한 뒤 기하를 learnable flow-state로 쪼갠다. 극한 결합조건에서는 전원 오차가 커진다 — 아키텍처가 아니라 레짐.
- Evidence: abs 2026-09-06; Jin/Yao/Guan/Li. Issue Board HTML: Emmi-Wing에서 Transolver 대비 REL-L2 **>20%** 감소·파라미터 **~14%** 감소, DrivAerNet++에서 AdaField 대비 REL-L2 **10%** 감소·파라미터 **~94%** 감소 주장. 청크 8192점. 에러맵 포화 ±0.015.
- Caveat: 수요일 이전 드롭 갭필러. 코드 없음 → Test 불가. REL-L2 감소는 적분 Cd/Cl 게이트가 아님. 극한 샘플에서 FSAN P95가 베이스보다 나쁠 수 있음.
- VA relevance: 공력 서러게이트가 전역 조건 임베딩만 자랑하면 국소 충격/박리 Cp를 놓친다.
- Action: Read/Cite

## Engineering-AI Pattern

**Do not ship a hybrid FV, a thermal PINN, a patch operator, or an aero surface net with only smooth L1 order, in-window R², patch RMSE, or a global (Ma, Re, AoA) vector.** Bind hybrid schemes to one local invariant-domain certificate for averages and point values (today IDP), bind extrapolation cards to sequential train–predict–validate–extend outside the Fourier window (today 09912), bind localized PCA to interface/spectral artifacts not patch RMSE (today Two-scale PCA-Net), and bind surface Cp to local flow-state not a single condition vector (today FSAN). A 0.99 R² inside the oven does not license the next Fourier number.
