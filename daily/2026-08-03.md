## New Papers / Tools

### HERO — history-enriched rollout training for autoregressive neural operators

- Link: https://arxiv.org/abs/2607.29135
- Type: Paper / neural-operator training method
- Why it matters: Absolute one-step or absolute trajectory loss alone is weak for long recursive rollouts because prediction error re-enters as input. HERO adds relative supervision from the model’s own optimization history so the operator is trained against the long-horizon failure modes it previously exhibited.
- Evidence: arXiv abstract frames history-enriched relative rollout supervision; Issue Board HTML harvest records FNO nRMSE@100 cuts such as Burgers 0.541→0.153, anisotropic diffusion 1.868→0.521, Kolmogorov 1.379→0.648, decaying NS2D 13.629→4.101, plus NS2D stable steps 17.6→26.5 on the HERO path, with little train slowdown and ~0 deployment overhead.
- Caveat: Periodic single-channel research PDE suite; not an industrial unstructured multiphysics product claim. Public code URL was not confirmed at scout time.
- Action: Read/Cite

### Data-free weak-form GNN PDE solvers

- Link: https://arxiv.org/abs/2607.27901
- Type: Paper / physics-informed mesh-native solver
- Why it matters: Builds residuals from the weak form with FE shape-function gradients instead of high-order autodiff, then uses residual maps as an inference-time acceptance/refinement gate. Useful pattern for geometry-family shift without a large labeled solution corpus.
- Evidence: Abstract reports residual convergence below 1%, generalization to unseen loads/geometries, and residual-driven test-time refinement; Issue Board notes displacement rel.RMSE narratives of &lt;5% without / &lt;3% with refinement on 3D hyperelasticity examples.
- Caveat: Primary evidence is quasi-static large-deformation solids, not turbulent CFD. Code availability not confirmed.
- Action: Read/Cite

### DFSC — error-controlled differentiable Mittag–Leffler substrate

- Link: https://arxiv.org/abs/2607.29038
- Code: https://github.com/hzhooning-art/DFSC
- Archive: https://doi.org/10.5281/zenodo.21588834
- Type: Paper + open-source differentiable fractional SciML layer
- Why it matters: Separates known fractional Mittag–Leffler propagation from learned residual dynamics, with adaptive truncation/Lanczos depth until successive differentiable evaluations meet a requested tolerance. Honest substrate work rather than a universal CFD replacement claim.
- Evidence: arXiv comment points to MIT code + Zenodo; GitHub `hzhooning-art/DFSC` is public MIT (0★ at fetch, pushed 2026-07-26). Issue Board HTML harvest cites amortized query speedups ~4.6–7.1× CPU and ~13–16× GPU (RTX 5070) for the propagator path.
- Caveat: Valuable when the fractional backbone is known; structural mismatch can erase bare-propagator advantage. Local install/smoke not yet run here.
- Action: Save/Test

### LLM fluid-system simulation code generation — syntax ≠ fidelity

- Link: https://arxiv.org/abs/2607.29389
- Type: Paper / agent evaluation benchmark
- Why it matters: LLMs can emit syntactically valid WNTR/Modelica code while simulation fidelity stays near zero. Compile-repair loops fix brackets/imports but not physical mapping or semantic errors — a direct harness lesson for CAE/CFD agents.
- Evidence: Abstract compares 10 LLMs and 6 prompting strategies with software-quality plus functional fidelity checks on fluid-system scenarios. Issue Board HTML harvest notes Modelica configs often at Simulation Fidelity 0.0 even when pass@3 exceeds ~0.9.
- Caveat: Modelica/WNTR fluid wrappers, not a full industrial OpenFOAM deck; small multi-run N noted by authors.
- Action: Cite

### BSG-VA — passing validation often lacks bug-discriminating evidence

- Link: https://arxiv.org/abs/2607.28871
- Type: Paper / agent verification measurement
- Why it matters: A passing test is not automatically evidence about the reported defect. BSG-VA replays captured validation commands on buggy / candidate / gold states and labels evidence roles, exposing evidence-inadequate closure.
- Evidence: Abstract reports 3,730 events / 643 rollouts / 110 tasks; 46.0% of positive comparable events carry no bug-discriminating information; 23.8% of baseline rollouts close with only that kind of positive evidence. Issue Board notes bug-contrast feedback cuts EIC by 7.8 pp and raises discriminating evidence by 7.4 pp on 109 paired tasks.
- Caveat: Program-repair domain; CFD/CAE transfer is pattern-level (evidence roles, not the exact numbers). Analysis code not publicly released at scout time.
- Action: Cite
