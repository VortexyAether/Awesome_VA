## New Papers / Tools

### Spray SDF-FNO — regime-agnostic interface operator (2D VoF)

- Link: https://arxiv.org/abs/2608.17825
- Type: Paper / multiphase neural operator (physics.flu-dyn + physics.comp-ph)
- Why it matters: 분무는 계면 면적이 폭증하면 CFD가 비싸지고 실험은 전 영역을 못 본다. 상태 표현·아키텍처·물리 정규화가 **장주기 자기회귀 계면**과 **보존**에 미치는 영향을 같은 VoF 코퍼스에서 가른다.
- Evidence: API 2026-08-18; Guida/Chen/Im/Roberts. HTML §6: SDF 표현이 직접 상분율 FNO 대비 상장 오차를 Δn=10에서 **약 3×** 감소; SDF-FNO proxy RMSE \\(\\alpha^p\\) **0.0171 / 0.0320 / 0.0408** (Δn=1/5/10). 고정격자에서 **U-Net이 최저 오차**(파라미터 미매칭). 재고 페널티 제거 시 상대 재고오차 Δn=1에서 **약 5×**. 물리 확장(증분 질량균형 + narrowband Eikonal + phase bound)은 안정 학습이지만 오차·IoU·재고가 데이터 베이스라인과 **케이스 산포 안** — 이득도 손해도 없음. 계면적 순위 ρ **0.93 → 0.73** (Δn=1→10).
- Caveat: 2D sharp-interface VoF. 공개 코드 미확인. 물리항은 경계 플럭스 강제 없이 CFD 라벨 감독. 공장 3D 분무 이전이 아님.
- VA relevance: 다중상 서rogate DONE = **표현 + 재고 게이트 + 순위보존**, 물리 손실을 붙였다는 문장이 아님.
- Action: Read/Cite/Save

### Residual LSTM on Wagner — transonic unsteady lift

- Link: https://arxiv.org/abs/2608.17894
- Type: Paper / aeroelastic residual learner (physics.flu-dyn + cs.LG)
- Why it matters: 고전 Wagner 비정상 이론이 구조화된 응답을 빼고, LSTM이 CFD−Wagner **잔차**만 배운다. 직접 양력 학습과 leave-one-out / leave-family-out으로 비교.
- Evidence: API 2026-08-18; Sanghi/Cesnik; 27pp / 21 figs / 9 tables. NLR 7301, 천음속 충격 운동. Table 7 외부벤치 5-seed NRMSE: residual **0.054±0.007** vs direct **0.065±0.009**. Pitch-only는 direct가 낫고 plunge/coupled는 residual. 4개 운동 패밀리에서 residual이 family-mean NRMSE를 낮춤.
- Caveat: 2D 익형. 고주파 일부는 direct가 우위. Mach 보간/3D 날개는 저자 향후 과제. 공개 코드 미확인.
- VA relevance: 저충실 이론이 분산을 줄일 때만 잔차가 이김 — **베이스라인이 구조를 빼는지**가 게이트.
- Action: Read/Cite

### Adaptive ST surrogate — rSVD + PNMAE/PNrMAE sampling

- Link: https://arxiv.org/abs/2608.17250
- Type: Paper / adaptive DoE for high-d spatio-temporal output (cs.CE; SMO)
- Why it matters: 고차원 시공간 출력을 rSVD로 잠복공간에 놓고 서rogate를 만든 뒤, **원공간 오차 = 재구성 + 서rogate**를 PNMAE/PNrMAE(노드 비율)로 보고 탐색+활용 적응 샘플.
- Evidence: API 2026-08-18; Kapusuzoglu et al.; MHI 지원. 정지 조건 예: 평균 PNrMAE **≤15%** 또는 N≥66. 가스터빈 블레이드 열-기계 다물리 예제.
- Caveat: 공개 코드 미확인. 블레이드 열-기계 — 외기 CFD 패밀리와 별개. 재구성 오차 분리는 저자 향후 과제.
- VA relevance: 필드 RMSE 한 줄 대신 **몇 % 노드가 물리 임계를 넘는지**를 적응 샘플 목표로 쓰는 언어.
- Action: Read/Cite

## Engineering-AI Pattern

**Score the representation, the residual target, and the node-wise threshold — not the architecture brand.** SDF vs volume fraction changes FNO error by ~3×; a liquid-inventory term buys conservation; a full physics-informed operator extension can train and still do nothing; residual learning wins only when the analytical baseline removes structure; high-d ST UQ should stop on the fraction of nodes past a physical MAE/rMAE gate.
