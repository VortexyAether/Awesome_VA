### DiffGeo — scarce-data aero generation, not another GAN airfoil dump

- Link: https://arxiv.org/abs/2609.00812
- Code: https://github.com/kfxw/DiffGeo
- Type: Paper + MIT latent-diffusion aero design (cs.CE)
- Why it matters: 극소 데이터에서 형상 타당·제약 가능 샘플을 만든다. 형상 표현과 설계 목표를 분리해 재사용하고, 에너지 기반 조건화로 구속을 건다.
- Evidence: abs 2026-09-01; Wei. cs.CE. AIAA Journal postprint DOI 10.2514/1.J066320. Abstract: 2D airfoil vs GAN/VAE, surrogate-optimization conditional sampling, 3D turbomachinery blades. Issue Board HTML: UIUC N=50–1000; LSM+LSDM 50장 학습 **671.9 / 716.4 s (V100)**; 무조건부 50샘플 **690.51 ms**; CGAN 면적 제약 오차가 한 자릿수 큼. GitHub `kfxw/DiffGeo` ★**2**, **MIT**, Python, pushed 2026-06-16.
- Caveat: FID는 형상 품질이지 양력/항력 QoI가 아님. SU2 NACA-0012는 데모 링크이지 자체 CFD 게이트가 아님. 레포가 논문보다 이름. 로컬 smoke 전 Test 보류.
- VA relevance: Urban_Flighter 형상 카드는 GAN 다양성이 아니라 **희소 샘플 + 구속 충족**. 어제 MIRAGE 시공 계획의 생성-기하 짝.

### RealCAD — parameter-frequency prior ≠ image-conditioned CAD

- Link: https://arxiv.org/abs/2608.30617
- Code: https://github.com/sunyh39/RealCAD
- Dataset: https://www.modelscope.cn/datasets/yeguomao/RealCAD
- Type: Paper + MIT image-to-CAD (cs.CV)
- Why it matters: DeepCAD 로컬 정규화가 좌표/반지름을 몇 칸에 몰아 찍기 점수를 만든다. 실사 도메인으로 바꾸면 명령 정확도는 조금 오르고 Chamfer는 실행이 아니다.
- Evidence: abs 2026-08-31; Tang. Abstract: OpenRealCAD = DeepCAD 392개를 3D프린트·4뷰 실사. Issue Board HTML: 스케치 좌표 128/176/223 = **61.62%**, 반지름 47–48 = **55.86%**; 개정 표현은 어떤 값도 좌표 **3.5%** 초과 안 함; 실도메인 Cmd **60.18→64.85%**, Para **52.03%** (ST+CL). GitHub `sunyh39/RealCAD` ★**1**, **MIT**, Python, pushed 2026-09-01.
- Caveat: 저자 스스로 mCD/IR 이득은 제한적이라고 적음. 문법 제약 디코딩은 future work. ★1.

### APPSolver — unstructured ship tokens lose to persistence at 1-step

- Link: https://arxiv.org/abs/2608.29355
- Code: https://github.com/wenhuahuo/APPSolver
- Type: Paper + MIT unstructured ship-flow surrogate (cs.AI + cs.LG)
- Why it matters: 정직한 음의 결과. 1스텝 MAE에서 persistence가 전 선체 최저. APP의 지원 이득은 예측 우승이 아니라 계산 예산이다.
- Evidence: abs 2026-08-29; Huo. 14 pages. Abstract: ShipBench DTC/KCS/KVLCC2; 학습 토크나이저가 APP-Transformer보다 정확; persistence가 1스텝 MAE 최저; APP-Transformer **1.815 GFLOPs / 1.309 ms**; 적응 분할이 균일+학습 대비 MAE **16.4–24.9%**. Issue Board HTML: 최강 학습모델도 persistence 대비 MAE **+17.4 / +6.8 / +9.7%**; Transolver **53.644 G / 24.767 ms**. GitHub `wenhuahuo/APPSolver` ★**0**, **MIT**, Python, pushed 2026-09-01.
- Caveat: 2D 수평 슬라이스. OpenFOAM-7 튜토리얼 선체. 절대 next-state는 장기 동역학을 증명하지 않음. Test는 데이터 무거움.
- VA relevance: 어제 GSNO 비정규 메시의 **1스텝 정직 벤치** 짝. nRMSE@1 ≠ 제품 서러게이트.
