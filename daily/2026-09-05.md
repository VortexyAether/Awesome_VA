## New Papers / Tools

### LatentDDM — freeze the local operator, learn only composition

- Link: https://arxiv.org/abs/2609.03069
- Type: Paper / neural-operator composition transfer (no public code in HTML)
- Why it matters: 전역 도메인 NO는 기하·크기·운전조건이 바뀌면 깨진다. 작은 서브도메인에서 연산자를 사전학습한 뒤, 새 설정에서는 **그 연산자를 동결**하고 로컬 예측을 잇는 가벼운 모듈만 학습한다.
- Evidence: abs 2026-09-02; Chen/Zhang/Deng. Title: Learnable composition for neural operators. cs.LG. Abstract/HTML: steady Darcy (장거리 압력) + unsteady pitching airfoil (롤아웃 누적). 더 큰 Darcy에서 16샷 후 capacity-matched 전역 모델 대비 오차 **36–56%↓**. 피칭 익형 20스텝 필드 롤아웃 zero-shot + few-shot. Issue Board HTML Table 1: 고정해상도 확장 protected-test Rel L2 **0.062–0.074**.
- Caveat: 저자 코드 URL 없음 → Test 불가. Darcy+2D 익형. AMReX `incflo` ★55는 솔버 인용이지 재현 패키지가 아님.
- VA relevance: 어제 SpeND 하드 프로젝션의 **전이 단위** 짝. Urban_Flighter 도메인 확장은 전역 재학습이 아니라 composition 모듈.
- Action: Read/Cite

### RealCADBench — executability, IoU, and Judge disagree

- Link: https://arxiv.org/abs/2609.03773
- Type: Paper / industrial intent-to-program CAD benchmark (dataset host unverified)
- Why it matters: 합성 CAD의 실행률·IoU 단일축을 깨는 **공장 자동화 19카테고리 12,632 과제**. 입력은 텍스트 / 2D 도면 / 실사진 / 렌더, Part+Assembly. 출력은 FreeCAD API Python → 공유 런타임. 평가 4축: 실행, Solid IoU, Surface IoU, 시각-의미 Judge. 9개 프론티어 중 **전 축 1위 없음**.
- Evidence: abs 2026-09-03; JoyIndustrial VisCAD Team (Cai et al.). cs.CV. Comments: Benchmark from JoyIndustrial's AI CAD project. Eval 1,770 (Part 1,745 + RCB-Assm25). 6개 규모 모델: 실행 **0.565–0.812**, Solid IoU **0.2841–0.5379**, Surface IoU **0.112–0.217**. RCB-Assm25에서 Codex+GPT-5.5는 실행/IoU를 올려도 Judge **−6.98 pp**.
- Caveat: RealCADBench 데이터/코드 릴리스 URL HTML 미기재 → Save 보류. `huggingface/cadgenbench` ★120 Apache는 **선행 벤치**. Judge는 LLM 루브릭.
- VA relevance: 수록 RealCAD `2608.30617` / MIRAGE-CAD의 **공장 인텐트** 짝. 실행 SR ≠ 조립 의미.
- Action: Read/Cite

### CAE harness — Direct + repair beats specialized multi-agent

- Link: https://arxiv.org/abs/2609.03718
- Type: Paper / CAE agent harness evaluation (no paper eval scripts in HTML)
- Why it matters: Foam-Agent / MetaOpenFOAM / ChatCFD류 멀티에이전트 스캐폴딩은 약한 베이스용이라는 주장. 정보 접근·수리 예산을 고정하면 **단일 에이전트 Direct Baseline**이 FoamBench **96.4% vs 특화 88.2%**. 실행-피드백 수리 0라운드 **71.8% → 96.4%**. 스크립트 reflection은 0. 남은 인간 입력은 솔버 튜토리얼 (**80.9 → 96.4**).
- Evidence: abs 2026-09-03; Shi/Zhang. cs.CE + cs.CL + physics.comp-ph. Title: What Do CAE Simulation Agents Really Need Beyond a Generic Harness? OpenFOAM·FEniCS·PyChrono·COMSOL. 논문이 실행 성공 ≠ 장 정확이라고 명시.
- Caveat: FoamBench 성공 정의가 수렴/LLM judge인 스위트가 있음. `Hmbown/CodeWhale` ★40916 MIT는 제네릭 코딩 TUI. 논문 전용 평가 스크립트 URL 없음.

### QoI twin — field NRMSE and gradient QoI collapse at different speeds

- Link: https://arxiv.org/abs/2608.29633
- Type: Paper / reduced-state scientific twin (no public code in HTML)
- Why it matters: 프라이머리가 끊긴 동안의 **인과 provisional**과 재동기 후 **미래 경계로 고치는 reconciled**를 분리. 추가 보정 네트워크 없이 시간 브리지 + 에너지 매칭. 필드 NRMSE와 그래디언트 QoI가 다른 속도로 붕괴한다.
- Evidence: abs 2026-08-30; Zhu/Klasky/Ranka et al. cs.CE. Title: QoI-Aware Provisional Rollout and Retrospective Reconciliation for Reduced-State Scientific Twins. JHTDB isotropic 16슬라이스×64패치, 갭 S∈{4,6,8}. S=8 풀 재조정: 윈도우 NRMSE **약 60%↓**, vx 글로벌 그래디언트 **4.21% → 2.91%**, 물리 보간은 같은 메트릭 **20.40%**.

- VA relevance: 어제 SpeND/인과 NO의 **트윈 운영 QoI** 짝. 필드 RMSE ≠ 트윈 수락.
- Action: Read/Cite
