## New Papers / Tools

### Convex Neural Energy Elements — geometry-param NO + FEM assembly

- Link: https://arxiv.org/abs/2608.02036
- Type: Paper / neural-operator FEM element library
- Why it matters: Extending fixed-geometry neural elements to a reusable geometry-parameterized library fails if the element only regresses fields: assembled Hessians can go indefinite and Newton can land in spurious minima. CNEE learns convex energy elements and keeps monolithic FEM assembly with stability/error framing.
- Evidence: Held-out multi-geometry assembly rel.L2 **0.72±0.33%** (median 0.62, max 1.67; 50 runs); Newton **2 iterations every run**; field-predicting NOE BC-pattern shift collapse **2.5% → 60–85%** contrasted in the paper.
- Caveat: No public code harvested; linear/convex trial-energy ladder is not a full NS-fluids claim.
- Action: Read/Cite/Save

### CADIR — cross-backend editable IR for agentic CAD

- Link: https://arxiv.org/abs/2608.00891
- Adjacent tool: https://github.com/NiJingzhe/SimpleCADAPI (★77, AGPL-3.0, pushed 2026-08-04)
- Type: Paper + adjacent open CAD API
- Why it matters: LLM CAD that emits backend-specific sequential scripts or static geometry loses editability and multi-backend handoff. CADIR targets a construction-graph style editable IR across CadQuery/build123d-class backends.
- Evidence: Table metrics include CADIR IoU **0.2702**, CD **18.36×10⁻³**, HD **0.2272**, exec success **1.0000**; vs strong baseline IoU **+4.9%**, CD **−8.2%**, HD **−5.4%**.
- Caveat: Geometric IoU/CD/HD ≠ manufacturing/printability/BRep validity/sim-ready watertight; SimpleCADAPI is adjacent, not the official monorepo; AGPL license gate.
- Action: Read/Test/Save

### Round-Trip Consistency — bidirectional diffusion predicts own rollout error

- Link: https://arxiv.org/abs/2608.00675
- Type: Paper / measurement-free rollout UQ
- Why it matters: Long autoregressive rollouts have no GT at deploy time. A single conditional latent diffusion model steps forward/backward via a direction flag and uses round-trip residual as a **measurement-free test-time error signal** — pairs cleanly with HERO-class nRMSE@H thinking.
- Evidence: MHD latent 16×16×4 setting; calibration tables for decoded reconstruction errors (coverage/ΔNLL protocol signal).
- Caveat: Plasma/MHD latent diffusion demo; not a drop-in CFD operator; no first-party code beyond HF diffusers chrome.
- Action: Read/Cite
