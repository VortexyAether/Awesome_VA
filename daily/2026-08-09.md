- Code: https://github.com/AGN000/AutoFOAM

### FALM-PINN — Fourier-enhanced alternating Levenberg–Marquardt

- Link: https://arxiv.org/abs/2608.05892
- Type: Paper / PINN optimizer + spectral-bias attack
- Why it matters: Treats PINN failure as **spectral bias + representation–coefficient coupling**, not only architecture shopping. Upper level learns Fourier features; lower level fits coefficients with LM.
- Evidence: Abstract/results — relative L² **up to ~2 orders** below SOTA baselines; 2D Klein–Gordon Table 1 style: Vanilla PINN **~8.11e-3** vs FALM converging to **~4.42e-4** after alternating phase (5-run mean±std reported in Issue Board harvest).
- Caveat: No code link harvested; classical PDE suite — industrial mesh/3D not shown.
- Action: Read/Cite

### CADCON — wrong design intent can be worse than none

- Link: https://arxiv.org/abs/2607.23191
- Type: Paper / CAD intent-conditioning causal audit
- Why it matters: Header conditioning gains can be circular. CADCON pairs CadQuery sketch-extrude with execution-level B-rep assertions and a **derangement-trained control** so wrong intent is measured as harmful, not “extra context.”
- Evidence: Qwen2.5-Coder-1.5B LoRA; 5-feature CADCON header; pre-registered {0%,40%} prefix × {correct,wrong,masked}. Conditional completion: wrong-header adherence **0.43 → 0.30/0.21 (text/token)** below no-header; derangement control immune (interaction p≤4.2e-3 on 3/3 seeds); at 0% prefix unconditioned baseline **0/100 executable**.
- Caveat: Small model + limited feature set; not full industrial GD&T. Code monorepo not harvested.
- Action: Read/Cite

### SCORE — self-concordant quasi-Newton PINN training

- Link: https://arxiv.org/abs/2608.04206
- Type: Paper / PINN optimizer
- Why it matters: Residual PINN curvature is indefinite/near-singular; SCORE uses decrement-coupled shifted secant quasi-Newton. Pairs with FALM as “optimizer axis” signal.
- Evidence: Burgers relative L² **SCORE 2.25×10⁻⁹** vs SSBroyden **1.40×10⁻⁸** vs BFGS **1.56×10⁻⁸**; multi-block stats; four nonlinear PDE suite.
- Caveat: No code harvested; classical PDE suite.
- Action: Read/Cite

### DMGS — differentiable multigrid linear solver for variational inference

- Link: https://arxiv.org/abs/2608.00760
