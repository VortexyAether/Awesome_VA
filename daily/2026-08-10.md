## New Papers / Tools

### WDR — training-free wireframe anomaly detection & repair for valid B-Reps

- Link: https://arxiv.org/abs/2608.04955
- Type: Paper / CAD validity gate (training-free post-process)
- Why it matters: Multi-stage B-Rep generators fail when wireframe self-intersections, edge collapses, and disconnects propagate. WDR intervenes **before final solidization** with GTAD (VLM ∥ geometry ∥ topology) + energy-guided selective repair — model retrain이 아니라 **validity gate**.
- Evidence (Issue Board HTML tables): DeepCAD-family Valid **79.5→95.6** (DTGBrepGen), **84.2→97.0** (Stitch-A-Shape), **85.3→97.4** (BrepForge); ABC DTG **68.1→83.9** with Novel/Unique ~99%; GTAD F1 **81.97%** (3-signal > single channel).
- Caveat: cs.CV framing; public code/license not on abs at curation; Valid% is kernel-checker dependent; industrial feature-tree CAD transfer unproven.
- VA relevance: Complements TraceCAD / RA-CAD / CADCON as the missing **geometry validity** stage in generate→execute/validate→repair harnesses for FreeCAD/CadQuery agents.
- Action: Read/Cite/Save

### scikit-rom — open Python platform for projection-based ROM

- Link: https://arxiv.org/abs/2608.04960
- Code: https://github.com/suparnob100/scikit-rom
- Type: Paper + early open tooling (education/prototype)
- Why it matters: Makes POD → Galerkin → offline-online → hyper-reduction (DEIM/S-OPT/ECSW/ECM) → Rel L2/RMSE/MAE/R² report an **inspectable stack**, not a black-box ROM GUI.
- Evidence: GitHub `suparnob100/scikit-rom` ★2, **license None**, pushed 2026-07-15. Demo accuracy reports (beam/linear) are teaching-scale, not industrial CFD claims.
- Caveat: No SPDX → cannot product-Save; teaching-first scope.
- VA relevance: Prototype substrate for surrogate harness accuracy contracts before CFD-scale hyper-reduction.
- Action: Test/Watch

### OPERA — operator-residual feedback for LM agents (optical experiments)

- Link: https://arxiv.org/abs/2608.05990
- Code: https://github.com/ningxu1995/OPERA
- Type: Paper + open method artifacts (MIT)
- Why it matters: Score-only agent loops produce **score↑ / physics flat** decisions at **23.6–39.0%** vs operator-residual **0.9–1.9%**; target maintain **75.8%** vs 33.9–60.1% refs. Same axis as AutoFOAM’s Physics-Validation Gap, different domain.
- Evidence: Three optical tasks; withheld physical reference; bootstrap 95% CI; repo ★1 MIT (pushed 2026-07-23).
- Caveat: Optics, not CFD; residual operators are domain-specific — transfer is design pattern, not drop-in OpenFOAM code.
- VA relevance: Cite when defining agent feedback as residual/force/QoI gates rather than LLM judge or proxy reward alone.
- Action: Read/Cite/Watch
