## New Papers / Tools

### Sensitivity-constrained neural operators — state fit ≠ Jacobian / inverse / rollout

- Link: https://arxiv.org/abs/2608.29888
- Type: Paper / neural-operator inverse + rollout (cs.LG)
- Why it matters: 상태값만 맞추면 입력–출력 응답이 안 묶인다. SC-NO는 미분 가능 솔버/이산 adjoint에서 뽑은 Jacobian 샘플을 학습에 넣고, 전체 Jacobian을 매 스텝에 걸지 않고 미니배치로 상각한다.
- Evidence: API 2026-08-30; Behroozi/Shen/Kifer/Lawson. Abstract: advection–diffusion, RANS–Spalart–Allmaras, input-dimensionality scaling, long-horizon autoregressive rollout, Tohoku tsunami source inversion. Inverse reconstruction gains exceed forward prediction. Issue Board HTML: rollout error **0.276 → 0.086 (~3.2×)**. 공개 코드 HTML 미기재.
- Caveat: 코드 경로 미확인 → Test 불가. 쓰나미는 near-real-time PoC. RANS 격자 64×64.
- VA relevance: Urban_Flighter 연산자 카드는 점 nRMSE가 아니라 **손잡이를 돌렸을 때의 응답**. 어제 conformal 공간 밴드의 짝.
- Action: Read/Cite

### Graph Spectral Neural Operator — spectral bias without domain warping

- Link: https://arxiv.org/abs/2608.29892
- Type: Paper / irregular-geometry neural operator (cs.LG)
- Why it matters: 비정규·기하 의존 도메인에서 스펙트럴 연산자. 그래프 라플라시안 기저 × 시간 푸리에 통합 커널. 워핑/보간/비싼 기하 임베딩 없이 전역 일관성.
- Evidence: API 2026-08-30; Behroozi/Shen. Abstract: zero-shot mesh-resolution and geometry-family claims; no autoregressive rollouts in the formulation. Issue Board HTML: AMG 대비 **64.8%** 오차 감소; SWE **0.0174 vs Transolver 0.0625 (72%)**; epoch 최대 **5×**. 공개 코드 없음.
- Caveat: 코드 없음. 기하 패밀리 폭은 본문 벤치에 종속. 산업 CAD 메시는 별 트랙.
- VA relevance: 어제 EFNO 주기셀 불변의 **비정규-메시** 짝. 격자 해상도 불변 ≠ 도메인 워핑 영수증.
- Action: Read/Cite

### MIRAGE-CAD — construction plan is the execution gate, not Chamfer

- Link: https://arxiv.org/abs/2608.28669
- Code: https://github.com/Cad-Kernel/MIRAGE-CAD
- Type: Paper + 0BSD executable CAD (cs.CV + cs.PL + cs.SE)
- Why it matters: 같은 최종 기하는 다른 시공 절차에서 나온다. NL / 렌더 / 포인트 / STEP/B-Rep → 공유 시공 표현 → 명시적 construction-plan → Python CAD → OpenCASCADE 솔리드·STEP. 문법 성공이 올라가도 Build/STEP은 반토막일 수 있다.
- Evidence: API 2026-08-24; Zhan. 64 pages. Abstract: 2,500 held-out queries/modality; Build **55.4–70.0%**, STEP **52.3–66.2%** without retrieval at inference. Issue Board HTML Table 4: 시공 경로 제거 시 Build **70.0→35.4**, STEP **66.2→34.6**; syntax **94.5→97.6**. GitHub ★**0**, **0BSD**, Python, pushed 2026-08-24.
- Caveat: ★0. STEP 입력은 전역 디스크립터(엔티티급 B-Rep 인코더 아님). 로컬 OCC smoke 전 Test 보류.
- VA relevance: Procedura mate/compile과 같은 축 — Chamfer/syntax 리더보드 폐기. 실행 = 따라 만들 수 있는 순서.
- Action: Read/Save

### TraCTra — sparse observations + differentiable forward model, no full-state labels

- Link: https://arxiv.org/abs/2608.30909
- Type: Paper / label-free flow reconstruction (physics.flu-dyn)
- Why it matters: 실험 역문제의 기본 형태. 부분 관측 시계열 + 미분 가능 전방 모델만으로 재구성 네트워크 학습. 네트워크 상태와 역학 진화가 상호 일치해야 한다.
- Evidence: API 2026-08-31; Zhu/Page. Abstract: 3D turbulence from coarse fields, velocity from density fluctuations, 2D shadowgraph→3D density/velocity, small-window observations→global vorticity. Beats assimilation-only and PINN-style baselines; holds outside the optimization window. Issue Board HTML: 3D Kolmogorov 상대오차 **ε~0.2**. 공개 코드 HTML 미기재.
- Caveat: Kolmogorov/섀도그래프. 도시 윈드 센서 배치는 재실험. Test 불가.
- VA relevance: 풀필드 라벨을 요구하지 않는 희소 센싱. SnapPINN 희소 스냅샷의 시계열 짝.
- Action: Read/Cite

### Simulator-backed agents — verification cadence is a protocol hyperparameter

- Link: https://arxiv.org/abs/2608.28147
- Type: Paper / agent verification harness (cs.SE + cs.AI)
- Why it matters: 설계를 고친 뒤 시뮬레이터 증거를 다시 살지는 모델이 자발적으로 안 한다. Cadence-Guided는 수정 후 새 시뮬레이션을 요청하라는 문장만 남김(하드 게이트 없음).
- Evidence: API 2026-08-28; Zhu/Tong/Ren. 12 pages, 2 figures. Abstract: DWSIM + valve pressure; 5 Qwen models × 8 synthetic cases × 3 repeats = 120 slots/condition. Re-verification **94/120 vs 32/120**; cadence violations 26 vs 87; bounded final success **95/120 vs 35/120**.
- Caveat: 공정 시뮬이지 OpenFOAM/CAD 아님. 합성 8케이스. 자발적 스테일 인식이 아니라 지시 준수 측정.
- VA relevance: draft≠review. FreeCAD MCP/OpenFOAM 에이전트에 옮기려면 스테일 케이스 증거가 필요. 문장 하나가 +50pp.
- Action: Cite
