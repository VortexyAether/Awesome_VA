## New Papers / Tools

### Implicit-adjoint FV CHT topology optimization (JAX)

- Link: https://arxiv.org/abs/2608.19426
- Code: https://github.com/smyng91/topology_optimization
- Type: Paper + MIT 2D FV / adjoint TO (math.NA)
- Why it matters: 밀도 기반 열–유동 TO의 재현성은 이산 솔버와 adjoint 역학에 달려 있다. 다공 Brinkman에서 가짜 열원을 막으려면 이산 이류가 셀마다 \(\mathbf{u}\cdot\nabla T=\nabla\cdot(\mathbf{u}T)-T(\nabla\cdot\mathbf{u})\)를 만족해야 한다 — **균일 T가 정확한 영공간**. 기울기는 반복 루프 언롤이 아니라 **음함수 정리 이산 adjoint**.
- Evidence: API 2026-08-19; Sam Yang. Stokes–Brinkman 또는 Darcy + 에너지, 고정 고체 체적. MMS + directional Taylor remainder. 4벤치(volume-to-point tree / Darcy convection / Stokes–Brinkman conjugate cooling / Dirichlet sandwich). GitHub `smyng91/topology_optimization` ★0 MIT pushed 2026-08-19. Issue Board HTML: \(v^*=0.45\), \(\alpha_{\max}=10^5\), \(\kappa_{\min}=10^{-6}\), 선형 잔차 **1e-7**, JAX.
- Caveat: 2D staggered MAC. 3D/난류/압축성은 별도. ★0 신생. 같은 저자의 `smyng91/hvac_designer`(08-22)와 별 레포.
- VA relevance: CHT TO DONE = **이류 영공간 + 언롤하지 않은 adjoint**. 역전파가 돌아갔다는 것만으로는 부족하다.
- Action: Read/Cite/Test/Save

### PCINN — Spatial-ALD coverage with an identifiability boundary

- Link: https://arxiv.org/abs/2608.00212
- Type: Paper / hybrid PINN + hard-coded ALD chemistry (cs.LG + physics.comp-ph)
- Why it matters: 고충실 CFD는 운전창 스캔에 너무 느리고 해석해는 gas curtain을 놓친다. 네트워크는 **벽면 농도 클로저만** 배우고, 표면 반응은 기판 궤적 적분의 **하드코딩 화학층**. 희소 데이터에서 빠르다고 끝이 아니라, Fisher/profile이 \(E_{\mathrm{ads}}, k_{\mathrm{des}}\)는 잡고 \(k_{\mathrm{ads}}\)는 한 온도에서 분리 불가로 표시한다.
- Evidence: API 2026-07-31; Hu/Liu/Jiang/Dong. Query **~7 ms**, CFD 대비 **~\(5\times10^4\times\)**. Test \(R^2_{\log}=0.998\), LOO \(R^2_{\mathrm{raw}}=0.974\). 30 training cases / 피복률 4 orders. 단일 온도에서 \(k_{\mathrm{ads}}\)는 \(k_{\mathrm{ads}} c_{\mathrm{wall}}\)만 식별. 4온도에서 \(\nu\)–\(E_{\mathrm{ads}}\) 기울기 **0.065 eV/decade**. 공개 코드 HTML 미기재.
- Caveat: 08-31 갭 필. 코드 없음 → Test 보류. SALD 컬럼 ≠ 외기 CFD.
- VA relevance: wafer/CVD 축. 피복률 서rogate DONE = **밀리초 + 어떤 상수는 분리 불가라는 영수증**.
- Action: Read/Cite/Save
