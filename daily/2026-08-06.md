### TraceCAD — trace-guided repair for agentic CAD

- Link: https://arxiv.org/abs/2608.03062
- Type: Paper / verification-first CAD repair layer
- Why it matters: LLM CAD agents lose requirements, faulty ops, and prior repair evidence. TraceCAD keeps **persistent recovery state + localized dependency-region search + execution/preservation checks + skill memory** — the runtime repair layer next to editable IR.
- Evidence: DeepCAD-derived 200-model ablations + 1K comparison; removing persistent state **nearly halves recovery**; removing localized search **more than doubles geometric regression** and doubles code-agent invocations. Implementation notes: Python 3.12 + SimpleCADAPI 2.0.0b3 → FreeCAD-compatible macro path.
- Caveat: Dedicated public TraceCAD repo not found today (paper-only); depends on SimpleCADAPI (already curated, AGPL). Backend-LLM sensitive.
- Action: Read/Watch (Save when code)

### Drawing-Recode — raster 2D CAD → parametric code with annotation grounding

- Link: https://arxiv.org/abs/2607.27558
- Type: Paper / manufacturing drawing digitization
- Why it matters: Pre-digital **raster drawings + dimension annotations** → parametric sequences. Cross-attention + Annotation Grounding Loss ties dims to geometry — often missing in CAD codegen papers.
- Evidence: Under noise, baseline CAD2Program MCD **+18.9%** vs Drawing-Recode **+3.7%**; Vanilla→cross-attn→+AGL ablation path.
- Caveat: Authors note scanned industrial drawings still limited/artificial; no public code harvested.
- Action: Read/Watch

### Multimodal AR transformer surrogate for geological CO₂ storage UQ

- Link: https://arxiv.org/abs/2608.02629
- Type: Paper / ops decision QoI surrogate + UQ
- Why it matters: Variable perforation/injection controls + 3D geomodel + relative-permeability scalars → auto-regressive multimodal transformer; pressure / mobile mass / injected mass under geological uncertainty — **ops QoI**, not field RMSE alone.
- Evidence: Median errors sat MAE **0.028**, pressure **0.21%**, total injected CO₂ **2.3%**, mobile mass ~3.3% (Issue Board HTML).
- Caveat: SEAM-like faulted aquifer; not open CFD drop-in.
- Action: Read/Cite
