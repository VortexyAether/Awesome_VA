## New Papers / Tools

### SnapPINN — freeze velocity, then Poisson from one sparse snapshot

- Link: https://arxiv.org/abs/2608.26711
- Type: Paper / sparse-sensing PINN (physics.flu-dyn + physics.comp-ph)
- Why it matters: 시간분해 없이 **한 장의 희소·노이즈 3D 속도 스냅샷**에서 속도·구배·압력·TKE 소산을 복원. 속도망을 먼저 맞추고 **동결**한 뒤 Poisson으로 압력을 푼다.
- Evidence: API 2026-08-27; Barta/Bauer/Bagheri. 3D DNS 난류 파이프, **100 케이스**. 시딩 **0.07–17.59%**. 벌크 U **<0.5%** (최희소에서도), 소산 **~50%** at f=0.07%, 사후 Re_τ **4–24%**. Issue Board HTML: 280000→1300 particles. 공개 코드 없음.
- Caveat: DNS 파이프 한 기하. 50% 소산 오차는 성공이 아니라 **희소 한계**. Test 불가.
- VA relevance: Urban_Flighter / 실험-CFD 게이트 = **벌크 RMSE ≠ 구배/소산 QoI**. 한 손실에 다 넣지 말 것.
- Action: Read/Cite

### DNO — Dirichlet as eigenfunction layer, not a data target

- Link: https://arxiv.org/abs/2608.27256
- Code: https://github.com/mtrautner/DNO
- Type: Paper + unlicensed neural operator (math.NA + cs.LG)
- Why it matters: 대부분 NO는 BC를 데이터로 근사. DNO는 각 층 출력을 출력영역의 **동차 디리클레 라플라시안 고유함수 span**에 넣어 학습과 무관하게 homogeneous Dirichlet을 만족.
- Evidence: API 2026-08-27; Stuart/Trautner. Lipschitz 유계 영역, 임의 메시. 보편근사 증명. Darcy Rel L2 median **0.772%** (best 0.482 / worst 2.02); Helmholtz median **0.130%** (best 0.0283). GitHub `mtrautner/DNO` ★0, license unset, pushed 2026-07-10. Description: blank FNO example to modify.
- Caveat: homogeneous Dirichlet만. ★0·SPDX 없음 → Test 보류. Darcy/Helmholtz는 박스 벤치.
- VA relevance: 기하 이동에서 **데이터로 벽을 외우는 NO는 샌다**. BC는 잠금.
- Action: Read/Cite/Save

### Mortar mixer — Np–Re plus numerical dissipation %

- Link: https://arxiv.org/abs/2608.27423
- Type: Paper / classical mortar FEM rotating mixer (physics.flu-dyn + math.NA)
- Why it matters: matrix-free 고차 CG + Mortar 로터-스테이터. ALE + SUPG/PSPG. 학습 헤드 이전에 **파워넘버와 수치점성 %**를 같이 보고한다.
- Evidence: API 2026-08-27; Campos/Munch/Ferreira/Boffito/Banquy/Blais. 2D Rushton 토크. 3D pitched-blade **Np vs Re = 1–2000** 실험 일치. 에너지 밸런스 수치점성 **1% (Re=200) / 10% (Re=2000)**. 대형 문제 이상적 strong scaling.
- Caveat: 고전 수치(AI 아님). 코드 링크 API 미확인.
- VA relevance: 회전체 기판 DONE = **QoI 곡선 + 숨기지 않은 수치점성**.
- Action: Read/Cite

### RTI ROM — put nonlinearity in dynamics or in the latent

- Link: https://arxiv.org/abs/2608.26783
- Type: Paper / RTI reduced-order model (physics.flu-dyn)
