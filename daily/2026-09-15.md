### OpenFOAM case-bundle — Build is review; Replay is 140 STLs; chat is not the artifact

- Link: https://arxiv.org/abs/2609.11941
- Type: Paper / OpenFOAM coding-agent operating model (cs.SE + cs.CE + cs.DC; CC BY 4.0; no public case bundle)
- Why it matters: 에이전트가 솔버를 “돌렸다”는 문장은 증거가 아니다. 저자는 검토된 케이스 번들(설정·메시·원격 실행·후처리·리뷰 기록)을 만들고, Replay로 인젝터 STL 패밀리를 완료한다. IteraSim/Foam-Agent 파도의 **운영 모델** 판: draft≠review를 디렉터리로 고정.
- Evidence: abs 2026-07-15, Monday cs.SE listing 2026-09-14. Xiao/Li/Zhang/Xu/Mao/Chen. OpenFOAM-7 interFoam VOF. Replay **140** STL on remote HPC (3 draft + 137 remaining). Pi runtime, four LLM backends, **all four runs succeeded**. Runtime only: `earendil-works/pi` ★**105115** MIT — generic agent toolkit, not a CFD Save.
- Caveat: 번들/스키마 미공개 → Test 불가. 단일 인젝터 스크리닝. 물리 QoI 리더보드가 아니라 완료·재실행 계약. 7월 leftover.
- VA relevance: OpenFOAM 에이전트 카드는 pass@k가 아니라 검토 번들 + Replay 완료.

### Aircraft surface ROM — in-domain LVAE MSE is not a 3D license; POD wins the zero-shot lift-drag gate

- Link: https://arxiv.org/abs/2609.12185
- Dataset: https://github.com/cashend/OptiWing3D
- Type: Paper / 2D→3D surface-field transfer (physics.flu-dyn; CC BY-NC-SA; dataset ★0, no SPDX)
- Why it matters: 2D에서 비선형 LVAE가 같은 차원 POD보다 재구성이 좋다. 3D 제로샷에서는 **선형 POD가 이긴다**. 게이트는 필드 MSE가 아니라 양력·항력. 어제 PINN 질량≠궤적과 같은 문장: in-domain 점수는 전이 점수가 아니다.
- Evidence: abs 2026-09-10; VanGessel/Diniz/Fuge. 2D latent **28–41**. Issue Board HTML Dataset1 LVAE MSE **3.01e-5** vs POD **8.53e-4** @dim 28. Extruded-wing POD Cl/Cd **0.1% / 0.7%**. BWB **0.3% / 0.7%** with no 3D training. Five BWB fine-tunes: MSE **5×** vs zero-shot, **70×** vs scratch. `cashend/OptiWing3D` ★**0**, license none, pushed 2026-01-07.
- Caveat: 표면압. 비정상/박리 일반화 미주장. ★0 + no SPDX → Test 보류. CC BY-NC-SA.
- VA relevance: 표면 ROM은 재구성 MSE가 아니라 형상-패밀리 Cl/Cd.
- Action: Cite

### PI-CP — residual is a nonconformity score; FNO equivariance needs coordinates before Dirichlet PDEs

- Link: https://arxiv.org/abs/2609.11935
- Type: Paper / physics-informed conformal UQ for neural operators (cs.LG; no public code)
- Why it matters: FNO 정확도와 dropout 분산은 공간 적응 UQ가 안 된다. PDE 잔차를 split-CP 점수에 넣으면 커버리지 계약 + 잔차 큰 곳 구간 확대. Dirichlet에서 좌표 채널이 없으면 Darcy rel_l2 **63% → 1%** (최대 **63×**).
- Evidence: abs 2026-06-26, Monday cs.LG listing 2026-09-14. Chin. Six physics (heat 2D/3D, structural 2D/3D, Darcy, NS). Four conformal methods **89–91%** coverage. MC Dropout **82–100%**. FNO vs CNN/DeepONet **10–12×**.
- Caveat: 교환가능성 가정. 산업 메시/비주기 형상은 벤치 외. 코드 없음 → Test 불가. 6월 leftover.
- VA relevance: 연산자 카드는 필드 RMSE가 아니라 구간 커버리지와 BC 좌표 채널.
- Action: Cite

### SNAP3D — Chamfer-complete parts are not an assembly; simulate standing rate

- Link: https://arxiv.org/abs/2609.13146
- Project: https://lucytuan.github.io/SNAP3D/
- Type: Paper / physics-guided part assembly from a single image (cs.GR + cs.CV; CC BY 4.0)
- Why it matters: 파트 생성기는 눈으로 완전해도 침투·연결 없음·중력 붕괴. 접촉 그래프 + 파라미터 커넥터 + 시뮬 피드백. 어제 canonical B-rep “파일 토폴로지 ≠ 솔리드”의 조립 판.
- Evidence: abs 2026-09-11; Tuan/Tsui/Ugrinovic/Kitani/Ma. Issue Board HTML Table 1: Ours Stable **95.0**, Falls **3.0**, IPR **0.5**. XPart Stable **0.0** / Falls **64.0** / IPR **31.8**. Ablation PGE+CGR **86% →** full **95%**. Stability = no intersection + worst free-part motion **<6%** / rotation **<10°**. Authors also 3D-print assemble.
- Caveat: 비전 파트 생성. BRep/STEP 커널 검증 아님. Genesis 시뮬은 기존 스택 — 오늘 Save 아님.
- VA relevance: CAD 인접 카드는 Chamfer가 아니라 서서 버티는 조립.
- Action: Cite
