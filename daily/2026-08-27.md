### PhysicsBench — one procedure for generative + predictive CAE

- Link: https://arxiv.org/abs/2608.24056
- Leaderboard: https://leaderboard.narnia.ai
- Data: https://github.com/Narnialabs/leaderboard
- Type: Paper / CAD-CFD-FEA benchmark (cs.LG + cs.CE)
- Why it matters: 생성 모델과 장/스칼라 예측을 **한 절차·한 제한 데이터 버킷(S/M/L/XL)** 으로 랭크한다. 무한 데이터 학술 순위는 소데이터 산업 순위를 예측하지 못한다.
- Evidence: API 2026-08-25; Lee/Jeong/Kang. 40 pages. Seven tasks; **66 models × 9 datasets → 28 configs**. Industrial CAD/CFD/FEA plus public refs (AirfRANS / DrivAerNet++ / DrivAerML / DeepJEB / DeepWheel). BenchRank debiases correlated metrics via PageRank over a head-to-head graph. GitHub `Narnialabs/leaderboard` ★0, license unset, pushed 2026-08-12.
- Caveat: ★0·SPDX 없음. 리더보드는 벤더(Narnia Labs) 운영 — 평가 절차는 논문, 거버넌스는 별도. 품질 뷰는 α·τ_d 노브에 민감.
- VA relevance: Urban_Flighter / 엔지니어링 에이전트 DONE = **제한 N + 기하 fidelity + 장/스칼라 + 공학 필드 메트릭**. 2D 랭크 ≠ 3D 랭크.
- Action: Read/Cite/Save

### Vortex-shedding LQG — higher-order ROM can lose the loop

- Link: https://arxiv.org/abs/2608.24435
- Type: Paper / closed-loop ROM control (physics.flu-dyn)
- Why it matters: 와류 억제에 **4차 이상이 필요**하지만 차수를 올리면 waterbed로 미모델링 대역 민감도가 커져 억제가 나빠진다. 잠복 콤팩트 ≠ 닫힌루프 안정.
- Evidence: API 2026-08-25; Proudfoot/Nicholls/Tang/Bacic. Re=1000 cylinder. DMD-c + LQG, lift-only. Best near **9 modes**; >14 modes drop. Lift-variance **−28.6 dB**, drag **−26%** in 2D. 2D URANS-trained controller on **3D DDES: Cd −13.7%**. Claimed code `Jackp-1/LQG-Cylinder-Control` GitHub API **404**.
- Caveat: 원주 벤치. 코드 404 → Test 보류. 저차 최적은 이 Re·양력 센서에 묶임.
- VA relevance: Urban_Flighter 제어 ROM DONE = **차수 스윕 + Bode/waterbed + 2D train / 3D deploy**. 모드를 더 넣으면 좋아진다는 가정은 깨진다.
- Action: Read/Cite

### IC-ThermBench — within-family OK, cross-package OOD collapses

- Link: https://arxiv.org/abs/2608.23977
- Code: https://github.com/Day333/ThermalBench
- Type: Paper + unlicensed thermal OOD bench (cs.CE)
- Why it matters: 레이아웃/물성/BC 패밀리 안에서는 쓸 만해도, **안 본 패키지**로 가면 열장 오차가 한 자릿수 켈빈에서 십수 켈빈으로 뛴다. 케이스당 라벨 10개 적응이 그 갭을 일부 메운다.
- Evidence: API 2026-08-25; Huang/Yang/Ding/Xin. 3D-IC steady/transient + industrial package + **50k** 2.5D chiplet. Best RMSE/MAE S4 **1.216 / 0.938 K** → S5 **15.99 / 15.00 K**; 10-label adapt MAE **2.60 K**. Eight baselines, common splits. GitHub `Day333/ThermalBench` ★29, SPDX **NOASSERTION**, pushed 2026-08-26.
- Caveat: IC 패키지 ≠ 외기 CFD. SPDX 없음. 시뮬레이터 도메인 타당성은 저자도 한계로 적음.
- VA relevance: 열/기하 서로게이트 DONE = **패키지/기하 가족 교차**. 패밀리 RMSE는 OOD 영수증이 아니다.
- Action: Read/Cite/Save
