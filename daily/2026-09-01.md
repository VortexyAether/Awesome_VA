## New Papers / Tools

### Conformal UQ for neural operators — coverage is a spatial quantile, not a point nRMSE

- Link: https://arxiv.org/abs/2608.28515
- Type: Paper / neural-operator UQ (math.NA + cs.AI + math.PR)
- Why it matters: split conformal이 **정규화 잔차장의 공간 (1−γ)-분위**로 스케일을 잡고, 점wise 밴드가 평가 도메인의 1−γ를 확률 ≥1−α로 덮게 한다. 연속/이산 모두 유한표본 주변 커버리지. 캘리브레이션 조건 커버리지는 **Beta**.
- Evidence: API 2026-08-28; Stent/Boullé. 19 pages, 6 figures. Abstract: Darcy + Navier–Stokes; 타깃 커버리지를 유지하면서 기존 보정 밴드보다 더 좁음. Issue Board HTML: Ma et al. 2024 대비 **N=16에서 1.78×, N=64에서 1.23×** (상대 폭; 우리는 더 좁다). 공개 코드 HTML 미기재.
- Caveat: 코드 경로 미확인 → Test 불가. 2D. 밴드 폭은 잔차 추정기 품질에 종속 (보장 ≠ 유용 폭).
- VA relevance: Urban_Flighter / 연산자 라이브러리는 **점 nRMSE가 아니라 공간 커버리지 영수증**. 어제 Wrong-Physics(파라미터 바꿔치기)와 직교하는 배포 패키지.
- Action: Read/Cite

### Euclidean FNO — integer Fourier modes are a different operator on a different cell

- Link: https://arxiv.org/abs/2608.28425
- Type: Paper / domain-transfer neural operator (cs.LG + cond-mat.mtrl-sci + physics.comp-ph)
- Why it matters: 표준 FNO 가중치는 **정수 모드 인덱스**. 주기 셀이 바뀌면 같은 가중치가 **다른 물리 파수**에 걸린다. EFNO는 스펙트럼 커널을 **물리 파수의 연속 함수**로 둔다. 격자 해상도 불변 ≠ 도메인 형상 불변.
- Evidence: API 2026-08-28; Bosch/Schmitz/Herbst. Abstract: heat equation + exchange-correlation potentials across crystal cells. Issue Board HTML Table 4: 직사각 등가셀 FNO Rel L2 **49.70%**, n=6 supercell **90.16%**; EFNO는 전 셀 **3.5×10⁻⁶**. 공개 코드 없음.
- Caveat: 주기 셀/재료 XC. 외기 CFD 비주기 경계는 미검증. Test 불가.
- VA relevance: 연산자 아카이브 DONE = **도메인 셀 스탬프**. 어제 파라미터 provenance와 같은 패키지의 두 번째 축.
- Action: Read/Cite

### Dimension-bridging 3D RANS — 2D airfoil coefficients corrected toward 3D wing QoI

- Link: https://arxiv.org/abs/2608.27639
- Type: Paper / multi-fidelity aero QoI (cs.CE)
- Why it matters: 반복 3D RANS는 설계 루프에서 비싸다. Gaussian Functional Regression이 **2D RANS 공력계수를 3D RANS 계수로 보정**. 차원 축소가 지배방정식을 바꾸는 쌍. adjoint inner-product 커널 + 적응 샘플. NN 가속 커널이 실시간 구간으로 끌어내린다.
- Evidence: API 2026-08-27; Lao/Scott/Bui-Thanh/Laiu/Bement. Abstract: fewer HD evals than stationary kernels; UQ drives adaptive sampling; NN kernel “millions of times” wall-clock. Issue Board HTML: 세 QoI에서 **1.93×10⁶** (단일 CPU, primal 재사용 포함). 공개 코드 없음.
- Caveat: 코드 없음. k-ω SST 클로저 고정. 날개/에어포일 패밀리 일반화 폭은 QoI-속도 중심.
- VA relevance: 2D rank ≠ 3D. Urban_Flighter 설계 루프는 **다운스트림 계수 + 적응 샘플 UQ**.
- Action: Cite

### Adjoint vs PINN inverse — the unknown’s representation picks the method

- Link: https://arxiv.org/abs/2606.12337
- Code: https://github.com/zhangzhen117/adjoint_PINN_inverse_comparison
- Type: Paper + MIT inverse-PDE comparison (math.NA + cs.LG)
- Why it matters: 동일 영역·PDE·관측·정규화·옵티마이저에서 adjoint vs PINN. 격자 필드는 discrete adjoint, 신경망 표현(클로저/구성방정식)은 PINN. 시간 의존은 adjoint가 궤적 저장에 지배되고 PINN은 더 싸게 재구성. **PINN warm-start adjoint**가 adjoint급 정확도를 약 절반 비용으로 회복.
- Evidence: API v2 2026-08-21 (v1 2026-06-10); Zhang/Alla/Karniadakis. 42 pages, 10 figures. Abstract: Burgers forcing, noisy Darcy, 3D Allen–Cahn, **unsteady NS viscosity**. Issue Board HTML: Allen–Cahn 5469 s → **2448 s**; NS는 Re=100 cylinder 희소 wake probe의 스칼라 점성. GitHub ★**1**, **MIT**, pushed 2026-08-21.
- Caveat: 6월 초판, 8/21 갱신. ★1. NS는 1파라미터 점성. Test는 로컬 smoke 후.
- VA relevance: 어제 Inverse-PINN 장≠파라미터와 같은 축의 **방법 선택**. 무엇을 찾느냐가 열쇠를 정한다.
- Action: Read/Cite

## Engineering-AI Pattern

**Do not ship an operator with only a point score.** Bind the tensor to the declared parameter (yesterday), the periodic cell / physical wavenumber (today EFNO), and a spatial coverage band (today conformal). A 2D airfoil rank is not a 3D wing QoI. An inverse field RMSE is not a method receipt — grid maps want adjoint, formula numbers want PINN. A residual-fit closure is not a long LES.
