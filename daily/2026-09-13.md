## New Papers / Tools

### NN SGS — a priori RMSE is not an LES license; train the filter shift and simplify the inputs

- Link: https://arxiv.org/abs/2511.17475
- Type: Paper / neural SGS closure (physics.flu-dyn + cs.LG; v2 replacement 2026-09-10; no public code in abs/HTML)
- Why it matters: 학습 잔차/필터 RMSE가 좋아 보여도 a posteriori LES에서 스펙트럼이 갈라진다. 저자는 두 LES 솔버(PadeOps, PadeLibs)에서 같은 주장을 버틴다. 기여는 멀티필터 증강과 입력 복잡도 축소. 복잡한 입력일수록 루프 안 붕괴가 크다. 어제 DiffSWE2d “그래프에 남는 연산”과 같은 축: 오프라인 점수는 솔버 루프 점수가 아니다.
- Evidence: abs v1 2025-11-21 / v2 2026-09-10; Wu/Lele. Related JFM DOI 10.1017/jfm.2026.11995. Issue Board HTML Table 2 a priori mean(std): NN-BoxDSCF-Simple-Original-G RMSE **0.757 (0.017)** DRMSE **0.672** Corr **0.661**. 원/투필터 a priori는 RMSE/DRMSE/Corr이 **5% 안**. a posteriori SSE는 log 에너지 스펙트럼 합 (PadeLibs k∈[0,35], PadeOps k∈[0,24]).
- Caveat: HIT 박스필터. 산업 벽난류/비구조 메시 아님. 코드 없음 → Test 불가. SSE 단일 우승 숫자는 표가 이미지라 고정하지 않음.
- VA relevance: 폐쇄 카드는 필터 RMSE가 아니라 솔버-패밀리 a posteriori 스펙트럼.
- Action: Read/Cite

### Ghost-cell IB — do not store geometry weights; the reconstruction must stay stable on a compact stencil

- Link: https://arxiv.org/abs/2609.10165
- Type: Paper / Cartesian embedded-boundary reconstruction (physics.flu-dyn; no public code in abs/HTML)
- Why it matters: 이미지점+행렬 역+기하 가중 저장은 CAD가 움직일 때마다 깨진다. Dirichlet/Neumann을 경계에서 해석적으로 걸고 최근접 스텐실만 쓴다. CGC는 Re 스윕에서 진동·발산. HGC/CGC_ES만 안정. 어제 canonical B-rep(2609.11573)과 짝: 기하 인터페이스는 파일 불변량이 아니라 재구성 계약.
- Evidence: abs 2026-09-09; Rapaka/Jagad/Addad/Riahi. Issue Board HTML Table 2 cylinder Re=100 HGC Cd **1.37** (Henderson 1.34, Mittal 1.35), CGC_ES **1.34**, St **0.17**. Re=40 HGC Cd **1.58**. 격자 0.015d. CGC는 Re<100에서 발산.
- Caveat: 직교 임베디드 경계. 다면체 OpenFOAM 임포트 아님. 코드 없음. 2차 공간.
- VA relevance: 벽 스티커를 저장하지 말고, 움직이는 솔리드에서 다시 그릴 수 있는 스텐실을 요구할 것.
- Action: Read/Cite

### Vectorial LBM — generic EOS plus shock capturing live in the relaxation, not in an ideal-gas fork

- Link: https://arxiv.org/abs/2609.10639
- Type: Paper / compressible Euler LBM (math.NA + physics.flu-dyn; CC BY 4.0; no public code in abs/HTML)
- Why it matters: 스칼라 모멘트 절단과 달리 벡터 개체군 + 시공간 적응 완화. 충격 없는 음향 스케일에서 Euler 2차. 이상/비이상 EOS를 한 솔버로. 어제 All-Mach(2609.10727, Cite-later)와 짝: 구성법칙/점프는 완화 단계에 살아 있어야 한다.
- Evidence: abs 2026-09-09; Hosseini/Karlin. Issue Board HTML: 강충격 튜브 N=2000, 밀도비 10^5, Mach **≈198**. 수렴 L2(ρ) vs δx, N=2000–7000. 원통 집속 임계 펄스 Mach **M0,c ≈ 0.0985**.
- Caveat: 고전 수치. ML 아님. 코드 없음. 산업 CAD 연동 없음.
- VA relevance: 압축 LBM 카드는 스무스 L2가 아니라 일반 EOS + 강충격 튜브.
- Action: Cite

### ARB preconditioners — the ROM is a Krylov tool, not a field surrogate

- Link: https://arxiv.org/abs/2609.11097
- Type: Paper / additive reduced-basis FGMRES preconditioner (math.NA; no public code in abs)
- Why it matters: 축소기저를 해로 팔지 않고 반복법 지렛대로 쓴다. 특이 ROM에 항등/투영 보정을 더해 비특이. 대류확산·이방 보텍스·Stokes·Helmholtz. 멀티쿼리의 온라인 시간이 제품 단위. 어제 MSFO(2609.11112)와 같은 축: 오프라인 투자 vs 온라인 쿼리.
- Evidence: abs 2026-09-10; Fan/Hu/Zhang. Issue Board HTML Table 1 대류확산 100 랜덤 온라인. GMRES+ILU iter **357.95±53.24** / **4.391±0.644 s**. AMG **5.05±0.22** / **0.525±0.019 s**. ARB M(1) **3.64±0.69** / **0.159±0.023 s**. 오프라인 ~104–107 s. Table 2 평균 가속 vs ILU **28.1×**, vs AMG **3.3×**.
- Caveat: 선형 정상/헬름홀츠. 비정상 NS 서러게이트 아님. 코드 없음.
- VA relevance: ROM 카드는 투영오차가 아니라 온라인 쿼리 시간과 비특이 조건.
- Action: Read/Cite
